# SideStore 安装与迭代包

[最新：1.5.3 build 16，缩放投影与启动加载修正](SHADOW_LAB_PREVIEW.md)。

在 Safari 下载后保存到「文件」，再打开 SideStore → My Apps → ＋，选择 MeadowJourney-b16.ipa 重签安装。安装名 MeadowJourney，包标识 com.liamchan.experiment.meadow，支持 iPhone／iPad 与 iOS 15 及以上，可覆盖已有安装。

[来源与校验值](MeadowJourney-build16.json) · [迭代日志](../docs/ITERATION_STATUS.md)。设备 Release 归档通过；iPhone 8 项原生与 2 项 UI 检查、iPad 2 项 UI 检查全部通过。放大对齐误差最高分别为 0.67 和 0.25 个缩小后分析像素；模拟器启动耗时约 6.17 秒和 15.48 秒，主线程最长停顿约 0.29 秒和 0.50 秒。SHA256SUMS 保存历次包的校验值。人物动画按用户要求留待后续。

历史版本：[1.5.2 build 15](MeadowJourney-build15.json) · [1.4.1 build 12 小场景](https://raw.githubusercontent.com/liamchan-rgb/experiment/feat/layered-living-scene/Downloads/MeadowJourney-b12.ipa) · [1.3.0 build 9](https://raw.githubusercontent.com/liamchan-rgb/experiment/feat/layered-living-scene/Downloads/MeadowJourney-v1.3.0-unsigned.ipa)。通用 MeadowJourney-unsigned.ipa 暂保留 build 9，当前请使用上面的 build 16 专用文件。旧版反馈和失败记录保留在对应日志。
