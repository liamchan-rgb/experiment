# iPad / iPhone 安装

[直接下载 MeadowJourney-unsigned.ipa](https://github.com/liamchan-rgb/experiment/raw/refs/heads/main/Downloads/MeadowJourney-unsigned.ipa)（约 9.9 MB）。

1. 在 Safari 中下载 IPA，保存到“文件”的“下载项”。
2. 打开已配置好的 SideStore → My Apps（我的应用）→ 右上角 ＋。
3. 在文件选择器中选中 `MeadowJourney-unsigned.ipa`，等待 SideStore 重签并安装。

IPA 是未签名的真机 arm64 安装包，需要 iOS / iPadOS 15 及以上。请从 SideStore 导入文件；“文件”App 的预览不会安装应用。私有仓库的下载链接需要登录有仓库权限的 GitHub 账号。

这个文件对应已通过 Xcode 编译、7 项测试与设备 archive 验证的 Demo。SHA-256 校验值见 `SHA256SUMS`。
