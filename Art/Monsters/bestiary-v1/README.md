# 六种怪物母版与动作图集 v1

来源：本轮image_gen生成母版atlas与独立补全史莱姆；原图保留。主体为当前项目新增候选，不代表用户已认可。非第三方游戏素材。原图RGBA有隐藏RGB，技术切片只依真实Alpha连通域，不把透明RGB当背景；六个独立连通域提取，无格线。史莱姆原atlas左缘触边，已换完整独立母版。

本轮使用同一母版的连续表面形变，离线采样为56张常规姿态（待机12、短出招24、施法12、受击8）及40张右吹消散；不是逐帧独立生成，也不是完整四肢骨骼行走动画。正向动作起末回同一母版；脚底固定(178.5,240)。常规画布384×256；死亡512×320，锚点(178.5,272)，首帧原身体只增加顶部32透明行，末帧全透明。表面形变幅度有限，不分切关节/衣物，避免脱节。每种固定调色板，不逐帧重新量化。alpha<64裁成透明以保持硬边；最终PNG为带透明索引的无损PNG。

普通显示比例0.88、首领1.04，相比原主角0.83保持主角尺寸；须看实际主体，不以翼/透明画布冒充体量。metadata contacts来自实际脚底轮廓，不套鹿四脚。原鹿及其攻击/死亡资源不变，按未映射模板走旧显示。新图集按当前战斗所需缓存，离场释放裁片缓存。

重建：仓库根目录 python3 scripts/build-monster-assets.py（Python3、Pillow、NumPy、SciPy）。清单manifest.json定义样本数、锚点、透明和资产名，运行时NSDataAsset只读取接触点；MonsterVisual.swift定义共享时序/姿态索引/显示比例/近远程规则显示。修改任一方须同步并验证。

入口：“开始新行程”设置 → “怪物动作检视”。正式行程仍可在“编辑地点”选择已登记模板，每个普通节点1—3只、首领1只。默认随机投放暂仍旧鹿灵/鹿王，下一轮再修改遭遇组合，规则/数值/掉落和已有存档目录不变。

审核需同时查看正常全场GIF、1×/2×整身、头尾衔接/透明边界、接敌/箭矢和吐息起点、主体与主角的比例，以及三敌纵深。设备运行交用户；离线光影和UI近似。
