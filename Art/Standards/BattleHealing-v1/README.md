# 治疗光效交付标准

用户于2026-10-26要求：治疗技能越强，光线越粗、效果越华丽。后续恢复技能以当前交叉双螺旋上升为基础，按技能本身的固定强度增加光带宽度、亮核层次、伴随星点和地面/环境染光；高阶可以增加外围较细螺旋、分层升起和更丰富收尾，保留身体轮廓、交叉深度和数字可读性。不能只把整张图统一放大、加亮至白屏，或一律套相同粗细。

强度由技能清单与演出设计决定，不随悬停时长增加、不新增蓄力层级，也不改变治疗数值。施法者与目标、实际受治疗者分别注册；满血无实际恢复不播放额外受治疗爆发。光带同人物父节点随动，后半由身体遮挡，前后连续采样；同一正常速度下检查出现/上升/交叉/尾光，不用慢动作掩盖抽帧。

本条为后续制作要求，本轮仅记录，未将所有现有恢复技能重新分级制作或扩大用户认可范围。
