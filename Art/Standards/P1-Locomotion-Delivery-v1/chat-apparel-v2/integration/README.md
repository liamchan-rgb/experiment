# 仅给接收方Codex：复用模组批量导出

Chat交五视角四层母版（每件20张），不是104次手绘。现有`build-b5-set-armors.py`与`armor-shared-surface-r4.py`有五视角→八方向→104姿势路径。只读旧脚本作方法参考，不运行它覆盖旧资源或重新输出被认为朴素的B5款充当新设计。

1. 检查母版文件、人工服帖与输入摘要，记录选型范围。
2. 登记到原静态参考/表面映射；新版型需要新裁片/控制点/边缘数据时，只更新新资源的authoring数据，不重做身体、关节、动作和层序。任意PNG不是零适配即可完美挂载。
3. 沿用五视角到八向关系，校正左右、近远、光照与装饰。必要时只补相应右向静态view。
4. 程序试出正下idle+8walk，查肩/袖腕/胸腹/腰裙，合成8×120ms正常GIF。同类问题优先修母版或共用映射并重导；个别特例记局部帧修正。
5. 批量出8×13姿势，每件104绑定/416引用，保留显式索引，原身体/旧组合不变。
6. 每件8种发型/五官/背剑组合实际合成832姿势；主线程亲查全身和正常GIF，修后再交用户。

`pose-export-plan-832.csv`是两件甲的程序输出计划，owner=Codex。默认各姿势四文件，允许经审核的PNG复用，但不减少绑定或用静止衣服凑动作。详见[POSE_EXPORT_SPEC.md](POSE_EXPORT_SPEC.md)。

这里只复用行走模组，不宣称战斗持弓/施法/倒地已齐；新运行时分支、女性体型、披风槽或新步态均不在范围内。

## 坐标格式不能混用

新任务默认每view的256母版已经对齐该向idle画布，应登记为该方向的rest pattern，再调用原运动映射。不能把它当成旧1774×887总图直接赋给旧sheet并套旧裁片坐标，那会二次注册或裁空。旧总图仅作技术示例；新设计的裁片/控制点由Codex登记，不能靠逐帧拉伸居中或改人体补救。
