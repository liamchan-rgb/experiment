# 给 Chat 的服装母版任务书 v2

**Chat 画母版，Codex 复用模组生成动作。不要把最终导出数量当成手绘工作量。**

本轮两件资源：星辉甲、龙纹甲。默认每件 **5个静态视角 × 4个独立衣物层 = 20张母版PNG**，两件共40张。这是五张静态视角母版各拆四层，不是20次互不相关的随机生成。Chat不需要手画104个姿势，不负责填写运行时104条绑定，也不需要自己制作行走GIF。

项目之前已经这样做过：`scripts/build-b5-set-armors.py` 读取五视角可编辑母版，通过 `armor-shared-surface-r4.py` 和原motion批量导出104姿势。旧款B5造型被指出过于朴素，但这条复用流程仍可用。参考包中的技术示例直接核对这一流程，不把旧造型当作新设计认可。

## 怎样交给 Chat

1. 上传 `Chat-Apparel-Masters-v2.zip`，粘贴 [CHAT_START.txt](CHAT_START.txt)（也有单独下载的TXT）。先让它实际解压、读文件、打开示例；仅给仓库路径不代表它能读到素材。
2. 第一轮只做两件甲各A/B/C方案，在同一个原人物的正下/左下静态模板上对比。分别选定后，先做正面四层样板，再补其余四视角。
3. 每件交20张母版PNG、真正分层源稿、母版清单、色板与五视角合成页。交回来后由Codex登记裁片/控制点、适配现有挂载并批量导出、修边和审核。
4. 不对称装饰或右向光照不能由现有映射妥善处理时，只补必要的右侧静态母版；不要因此改成全套逐帧手绘。

## 两个工作量要分开

| 工作 | 单件甲数量 | 谁做 |
| --- | --- | --- |
| 原创设计选择 | A/B/C，各正面+左下预览 | Chat绘图，用户选型 |
| 静态母版 | 5视角×4层＝20张PNG，允许真实合法复用 | Chat |
| 右向补图（确有需要才做） | 最多补右/右下/右上3视角×4层 | Chat或Codex精修，列明具体原因 |
| 注册/裁片/左右与光照适配 | 20母版到现有8方向模板 | Codex，复用原模组，不重设计人体/步态 |
| 正下试导出 | idle+8walk＝9绑定/36层引用 | Codex程序生成并审核，不让Chat手画36张动作图 |
| 完整行走输出 | 8方向×13姿势＝104绑定/416层引用 | Codex批量导出；不是104次重新画衣服 |
| 组合与正常GIF | 8组合×104姿势；8向walk与起停 | Codex自审、修复后交用户 |

`templates/master-delivery-plan-40.csv` 才是给绘图Chat的母版清单。`integration/` 内104绑定/832引用计划是接收方Codex的后续工作，不是Chat的绘图任务。

## 保持的东西

沿用原身体、头发、五官、裤靴、背剑、关节、动作、步相、逐帧drawOrder和固定左上光。新设计放新目录，不覆盖旧B5候选或已存在的服装。肩甲归对应袖层，随原手臂运动；需要新增披风/尾巴/长后裙层序的方案另列扩展，不夹在换装任务内。

本包是美术母版任务与实际参考，尚未制作两件新的甲；不意味着104姿势已完成、用户已认可或已接入游戏。任务只含行走衣甲，不包含新战斗动作、女性身体、运行时代码改造、IPA或实机测试。
