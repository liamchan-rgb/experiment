# Dragon Soul Ward — Integration Notes

## 1. 动画用途与技能效果

技能名称：**龙魂庇护**

- 作用范围：节点内所有友方单位。
- 当前配置效果：恢复 **10 HP**、获得 **10 点护盾**、攻击力 **+3**，持续 **2 回合**。
- 本素材包只提供龙魂庇护独有的「龙魂降临与力量注入」视觉。
- 攻击力 +3 的持续时间由游戏状态管理系统负责；不通过额外循环动画表达。

## 2. 治疗与护盾资源复用

## 3. 动画与精灵表规格

- 动画：一套完整、连续、一次性动画；不拆分任何子动画。
- 实际帧数：**20 帧**。
- 单帧尺寸：**256 × 256 px**。
- 精灵表：**5 列 × 4 行**。
- 精灵表总尺寸：**1280 × 1024 px**。
- 格间距：**0 px**；外边距：**0 px**。
- 所有帧均为 RGBA PNG，具有真实 Alpha 透明背景。

### 固定格子切分

按从左到右、从上到下的 row-major 顺序切分，索引从 0 开始：

- `row = index // 5`
- `col = index % 5`
- `x = col × 256`
- `y = row × 256`
- 每格裁切尺寸固定为 `256 × 256`。

帧索引 `0` 至 `19` 对应独立帧文件 `dragon_soul_ward_000.png` 至 `dragon_soul_ward_019.png`。

## 4. 播放方式

- 播放顺序：`0 → 1 → 2 → … → 19`。
- 建议帧率：约 **12 FPS**，每帧约 **83 ms**，整段约 **1.66 秒**。
- 循环：**否**。这是一次性完整动画，不应循环播放。
- 结束处理：最后几帧逐渐淡出；播放完成后停止并清除动画图层，不保留静态残影。
- 不要为了循环而将首尾帧强行拼接。

## 5. 锚点、坐标基准与叠加注意事项

- 建议统一锚点：**`(133, 154) px`**，对应灵魂核心/能量汇聚点附近。
- 画布尺寸与锚点在全部帧中保持一致；不要对单帧单独自动裁边、自动居中或重新计算 pivot。
- 精灵表每格均保留完整 `256 × 256` 矩形画布；不得紧密裁切后再拼表。
- 播放期间禁止逐帧随机旋转、缩放、横纵漂移或更改锚点。
- 建议使用 Point / Nearest-neighbor 采样，避免像素轮廓被双线性过滤模糊。
- 与单位锚点、节点坐标系及其他特效的实际叠加偏移：**待确认**。
- 图层排序、混合模式及目标单位的渲染层：**待确认**。
