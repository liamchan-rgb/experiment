# Rally（振奋）动画帧清单

## 动画概述

- 技能 ID：`rally`
- 技能名称：振奋
- 用途：当前节点内所有友方单位共享播放的一次性群体攻击强化特效。
- 技能效果：攻击力提升 2，持续 1 回合（`damageBuff`）。
- 目标：`alliesAtNode`；战斗与非战斗阶段均可使用。
- 特效内容：金橙色战意核心、断续共鸣弧段、金白放射光线、少量橙金火星与菱形能量粒子。
- 动画组织：**一套完整连续动画，不拆分子动画**；不包含单位、武器、治疗、护盾或伤害视觉。
- 实际帧数：20 帧（索引 `0–19`）。

## 尺寸与精灵表规格

| 项目            |                      数值 |
|-----------------|--------------------------:|
| 单帧宽 × 高     |              256 × 256 px |
| 列数 × 行数     |                     5 × 4 |
| 精灵表总宽      |         5 × 256 = 1280 px |
| 精灵表总高      |         4 × 256 = 1024 px |
| 精灵表文件      |   `rally_spritesheet.png` |
| 格间距 / 外边距 |               0 px / 0 px |
| 帧格式          | RGBA PNG，真实 Alpha 透明 |
| 帧文件目录      |                 `frames/` |

精灵表严格按行优先（row-major）排列，索引从 0 开始：

`index = row * 5 + column`

行、列均为从 0 开始的索引。精灵表由最终独立帧 PNG
逐格原样合成；从精灵表按 256×256 切分得到的帧与对应独立 PNG 逐像素一致。

## 安全边距与母版保留

- 原始生成母版保留为 `rally_master_source.png`，尺寸 1536 × 1024
  px，RGBA；该文件未经修改保存，作为唯一视觉源图。
- 母版本身为 5×4 动画阶段排布。为统一运行时格子尺寸，按 5×4
  单元提取后，将每格内容等比例适配至 234 × 195 px，再居中放入 256 × 256
  px 透明帧画布；未重新绘制主体。
- 每帧内容区从 `(11, 30)` 开始，内容区尺寸 234 × 195
  px；因此四周至少保留左/右 11 px、上 30 px、下 31 px
  的透明留白，满足每侧至少 4% 且不少于 8 px 的安全边距。
- 所有帧共用相同画布、视觉中心、中心锚点与缩放基准。母版源文件保留原始生成像素；运行时帧与精灵表采用统一安全区适配版本。

## 播放参数

- 播放顺序：`0 → 1 → … → 19`。
- 建议帧率：12 FPS。
- 建议单帧时长：约 83 ms。
- 预计总时长：约 1.66 s（20 × 83 ms）。
- 循环：否，一次性播放。
- 结束处理：播放完索引 19
  后结束本次特效实例并释放显示；不保留循环光环或持续状态动画。增益持续 1
  回合由游戏状态逻辑处理。

## 文件校验约定

- 所有独立帧均为 256 × 256 px、RGBA PNG。
- 精灵表为 1280 × 1024 px、RGBA PNG，5 列 × 4 行，零间距、零外边距。
- 精灵表第 `n` 格坐标为：`x = (n % 5) * 256`，`y = floor(n / 5) * 256`。
- 不在图片中绘制编号、文字、标签、边框或网格线。
- `rally_preview.apng` 仅为可选预览，不替代独立 PNG
  帧、原始母版或精灵表。
