# Rally（振奋）VFX 交付包

- `rally_master_source.png`：原始生成母版，原样保留。
- `rally_spritesheet.png`：运行时精灵表，5×4，1280×1024，RGBA。
- `frames/`：20 张独立 RGBA PNG 帧，256×256。
- `rally_frame_manifest.md`：逐帧清单、尺寸、索引与播放参数。
- `rally_integration.md`：技能语义、切分、播放、锚点与待确认项目接口。
- `rally_preview.apng`：可选一次性动画预览。

本交付只包含一套完整连续动画。项目内资源路径、播放器、事件接口、锚点名称与
API 未从项目资料核实，文档中均标注为“待确认”。
