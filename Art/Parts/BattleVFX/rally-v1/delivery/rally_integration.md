# Rally（振奋）接入说明

## 1. 技能与视觉用途

- 技能 ID：`rally`
- 技能名称：振奋
- 目标：当前节点内所有友方单位（`alliesAtNode`）。
- 使用阶段：战斗与非战斗阶段均可使用（`both`）。
- 效果：攻击力提升 2，持续 1 回合（`damageBuff`）。
- 视觉用途：播放一次统一的金色战意共鸣脉冲，表达同一节点内友军同时获得攻击强化。
- 本技能没有治疗、护盾或伤害效果；不调用现有治疗或护盾资源。
- 本交付只包含一套金色战意共鸣完整动画，不为每个友军分别播放独立动画，也不制作持续状态循环动画。

## 2. 文件与精灵表切分

| 项目            | 配置                                             |
|-----------------|--------------------------------------------------|
| 精灵表          | `rally_spritesheet.png`                          |
| 独立帧          | `frames/rally_000.png` 至 `frames/rally_019.png` |
| 单帧尺寸        | 256 × 256 px                                     |
| 列数 / 行数     | 5 / 4                                            |
| 精灵表总尺寸    | 1280 × 1024 px                                   |
| 格间距 / 外边距 | 0 / 0 px                                         |
| 索引顺序        | 行优先，0-based                                  |
| 索引公式        | `index = row * 5 + column`                       |
| 帧数            | 20                                               |

切分时使用固定 256 × 256 矩形，不做紧密裁切：

- `x = (index % 5) * 256`
- `y = floor(index / 5) * 256`
- `width = 256`
- `height = 256`

索引 0 位于第 0 行第 0 列；索引 19 位于第 3 行第 4
列。精灵表由独立最终帧合成，按上述坐标切分后应与对应
`frames/rally_NNN.png` 逐像素一致。

## 3. 播放方式

- 播放顺序：0 至 19，顺序播放。
- 建议帧率：12 FPS（约 83 ms / 帧）。
- 建议总时长：约 1.66 秒。
- 循环：关闭；这是一次性施放动画，不是持续状态动画。
- 结束处理：播放完最后一帧后结束并移除该视觉实例；不要自动回到第 0 帧。
- 触发时机建议：与 `damageBuff`
  实际生效的逻辑时点同步，以避免视觉先于或晚于增益结算。具体事件名、事件总线或回调接口：**待确认**。
- 该特效只播放一次统一群体动画，不按目标数量复制，也不为每个单位叠加独立光环。

## 4. 锚点、坐标与叠加

- 统一锚点建议：每帧画布几何中心 `(128, 128)`；所有帧使用相同锚点与相同
  256 × 256 坐标基准。
- 位置基准建议：以当前节点受影响友方单位集合的公共视觉中心作为一次性特效位置；具体节点坐标来源、目标集合中心计算方式及锚点名称：**待确认**。
- 帧间对齐：不要对单帧单独自动裁边、自动居中或按非透明包围盒重新定位；始终以
  256 × 256 完整帧画布对齐。
- 透明边缘：每帧至少保留左/右 11 px、上 30 px、下 31 px
  的透明安全边距。不要在导入时裁掉透明留白。
- 叠加：建议以 RGBA Alpha
  正常合成；若引擎启用加色混合，需统一应用于整段动画并检查高亮溢出。避免逐帧改变缩放、旋转或位置。
- 不要把动画误配置为护盾、治疗、伤害或持续增益循环特效。
