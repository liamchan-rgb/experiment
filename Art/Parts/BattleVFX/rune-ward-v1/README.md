# 符文庇护节点施法特效

这是用户提供的20帧、1.44s、256×256 RGBA几何符文阵。原包、精灵表、帧清单和每帧PNG均保留在本目录；游戏资源名为 `MeadowRuneWardCast01` 至 `MeadowRuneWardCast20`。

在符文庇护动作开始时，于受影响队友所在节点的中心播放一次。第13帧为短暂峰值；不循环、不为每个队友重复绘制。该素材只承担节点级施法启动，真实恢复与圆形护盾继续由既有回执反馈和资源处理，不用这张阵列代替护盾状态。

完整场景离线合成见 `Art/Review/Battle/spellblade-demo-v1/runeWard-normal.gif` 和相邻关键帧；这不是UIKit或设备运行截图。
