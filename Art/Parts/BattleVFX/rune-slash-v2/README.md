# 符文斩攻击特效 V2

这是用户提供的20帧攻击序列。原始压缩包、精灵表、帧清单和每帧PNG均保留在本目录；游戏资源名为 `MeadowRuneSlashAttack01` 至 `MeadowRuneSlashAttack20`。

一次播放，总时长955ms。以技能的真实伤害回执1.048s为权威时点，帧索引10（文件 `frame_010.png`，资源 `Attack11`）从回执开始；因此序列在动作龄0.643s起播。相邻源帧在每个帧时段内平滑交叠，最后的透明帧收束，不循环、不控制伤害。

峰值白核位于帧画布中心右侧约52px、下方约20px。渲染锚点按此偏移校正，让白核落在武器实际命中位置。命中回执同步生成蓝白碎片、金色火星、目标受光和地面闪光；碎片有重力弧线及短暂落地反弹/碰撞光。粒子由采样龄驱动，伤害仍只由规则回执提交。

RGB透明边缘、角色比例和战斗环境整场合成见 `Art/Review/Battle/spellblade-demo-v1/runeSlash-normal.gif` 与相邻关键帧。本轮只作离线美术合成审核，不代表UIKit或设备运行结果。
