-   资源名：`rune_slash_attack`
-   触发点：符文斩攻击动作开始时播放；具体事件名 **待确认**。
-   播放模式：一次性播放，不循环。

-   命中视觉峰值：帧索引 9--10（`frame_009.png`--`frame_010.png`）。
-   建议以游戏战斗逻辑的真实命中/伤害事件作为权威时序；若命中时间不同，应调整

-   播放结束：到达全透明帧 `frame_019.png`

-   锚点：默认画布中心
    `(128, 128)`。如果项目使用目标点或攻击方向锚点，需在实际游戏内验证位置偏移。
-   缩放：整个序列使用同一缩放值；不要逐帧自动紧密裁切。

## 4. 精灵表切分

精灵表尺寸为 **1280×1024 px**，网格 **5 列×4 行**，单帧 **256×256
px**，格间距和外边距均为 0。

对零基帧索引 `i`：

``` text
col = i % 5
row = floor(i / 5)
x = col * 256
y = row * 256
width = 256
height = 256
```

索引按行优先排列：0--4 为第一行，5--9 为第二行，10--14 为第三行，15--19
为第四行。若引擎支持直接导入精灵表，可按上述固定网格切分；否则读取独立帧
PNG。不要使用自动紧密裁切或 trim 功能，以免锚点跳动。

## 5. 治疗资源复用规则

符文斩本身不绘制治疗图案。技能结算后：

1.  比较结算前后的实际 HP，计算本次实际恢复量。
2.  **实际恢复 HP \> 0**
    时，调用项目已有的通用三档回血特效，并按项目现有阈值/规则选择档位。
3.  **实际恢复 HP = 0** 时，不播放治疗特效。
4.  三档阈值、资源路径、接口名称均
    **待确认**；不要在本次素材包内新增治疗图片、精灵表、循环动画或变体。

## 6. 护盾资源复用规则

若技能结算后实际获得护盾，则调用项目已有的半透明蓝色圆形护盾资源。护盾资源路径、接口名称及触发事件均
**待确认**。不要在符文斩攻击帧或精灵表中绘制蓝色护盾圆、护盾环或替代性护盾图案。

## 7. Alpha、边缘与锚点注意事项

-   全部独立帧为 RGBA PNG；精灵表也为 RGBA PNG。
-   背景使用 Alpha 透明，不以黑底、白底或棋盘格伪装透明。
-   帧间不包含分隔线、编号或文字。
-   所有帧固定为 256×256 px，保持统一画布中心和缩放比例。
-   如果引擎使用预乘 Alpha，按项目现有 VFX 资源的导入规范处理；具体设置
    **待确认**。
-   在深色和浅色战斗场景中各做一次检查，确认没有明显矩形背景、边缘黑边或不必要的光雾。
-   确认最终一帧完全透明，且特效结束后不会留下常驻渲染对象。
