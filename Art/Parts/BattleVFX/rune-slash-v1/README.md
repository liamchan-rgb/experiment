# 符文斩精灵表 v1

来源：`source-spritesheet.png`，2048×256 RGBA，横向八格；按 x=0…7×256 精确拆帧，输出 `frames/rune_slash_01.png`…`rune_slash_08.png`（256×256 RGBA）。拆分不缩放、不重采样、不自动去边；保留原始像素供追溯。对应游戏图集名和帧阶段见 `frames/frame-manifest.json`。

动画语义按上传说明：01凝聚、02弧斩显现、03符文点亮、04全力释放、05命中爆发、06余波、07消散、08淡出。帧05从动作时钟 1.048 秒起播，与现有伤害回执时点一致。序列显示在真实命中点，攻击者按近战轨迹接敌并回位；规则骰值与扣血仍只在原回执时提交一次。

这批图是概念裁切的初版参考，浅色底上可见部分半透明深蓝外缘，帧05的爆发构图也明显区别于弧斩帧。导入前确认八格尺寸、RGBA、四边透明留空与视觉中心；未声称修过逐像素边缘或重绘帧。正式生产验收仍需逐帧检查透明边缘、弧形方向、中心漂移和循环节奏。

游戏资源位于 `Sources/Resources/Assets.xcassets/MeadowRuneSlash01…08.imageset`。序列统一以命中点上方32个逻辑点为画布中心，使第05帧的亮核落在目标躯干，另由地面光照亮脚下。只有符文斩播放此序列；符文庇护与战斗符文仍使用原独立几何光效。离线审核动图在 `Art/Review/Battle/spellblade-demo-v1/runeSlash-normal.gif`；它不是UIKit或实机录屏。用户实机效果待审。
