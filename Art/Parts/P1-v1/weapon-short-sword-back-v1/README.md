# Short sword back-carry candidate v1

This down-facing independent sheathed short-sword resource owns only `weapon.back` and declares `carryProfile: back-scabbard`. It has no grip, hand, clothing, or character pixels and is intended to render behind the character.

The current output maps the entire original 1254×1254 RGBA source canvas to the 256×256 character cell with one fixed affine transform. It uses uniform scale 0.12 and Pillow positive 18° with `x_cell=a*x_source+c*y_source+tx`, `y_cell=b*x_source+d*y_source+ty`: `a=0.11412678195541842`, `b=-0.03708203932499369`, `c=0.03708203932499369`, `d=0.11412678195541842`, `tx=24.893786930009668`, `ty=108.25463222465483`. The source landmark (460,340) maps exactly to (90,130); the approximate scabbard tip (790,920) maps to (149.17,183.96). The registered alpha bounds are x=84–151, y=125–187. No source alpha threshold, crop, alpha-bounds resize, or content-dependent fit is used. After transformation, the script removes only four disconnected one-pixel components with alpha below 8, recorded with exact coordinates in `source/registration.json`.

The final placement was selected in the actual v8 commonbase + chestnut hair + blue face + Forester outfit compositor. Rebuild the part from the source from the repository root with `python experiment/Art/Parts/P1-v1/weapon-short-sword-back-v1/source/register-back-sword.py`; rebuild actual v8 previews with `python experiment/Art/Parts/P1-v1/weapon-short-sword-back-v1/source/render-v8-composition-review.py`. The actual nine-pose whole-body board is `review/v8-relaxed-clothed-angle18-nine-poses.png`, with a 120ms walk cycle at `review/v8-relaxed-clothed-angle18-120ms.gif`. This placement keeps the pommel/hilt outside the screen-left shoulder and exposes a continuous sheath tip below the screen-right waist while keeping the sheath behind the body and sleeve.

The nine pose maps use the same fixed affine and only the authored integer body-bob offsets: idle00=(0,0), walk01=(0,0), 02=(0,2), 03=(0,-1), 04=(0,-2), 05=(0,0), 06=(0,2), 07=(0,-1), 08=(0,-2). No per-pose rotate, scale, crop, or fit is applied. The former bbox-fit registration, previous 22° registration, and intermediate 18°/−8px placement are preserved in `source/registration-rejected-bbox-fit-v1.json`, `source/registration-angle22-superseded-v1.json`, and `source/registration-angle18-offset-minus8-superseded-v1.json`; none feeds current exports. Editable SVG and ORA contain the current idle export.

This remains an internal candidate with `artApproval: null`, down-facing only. Visual review is pending; the preview does not establish art approval or production acceptance.
