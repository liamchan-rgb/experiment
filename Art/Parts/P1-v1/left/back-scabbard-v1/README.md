# 左向独立背负短剑 v1

重用已有短剑/棕皮鞘的未改动生成源，按明确柄部与鞘尖标志作一次固定整画布仿射，得到左向背负视图。只包含 weapon.back，不包含皮肤、手、服装或握点。背负武器位于身体/衣物/头发后方，由公共层序先绘制。

同一张256²透明PNG覆盖13个绑定：idle0、walk1–8、walk-start1/2、walk-stop1/2。图像复用不改变动作覆盖合同；不跟随头部摆动、不按角色外观改身体。原画布1254²、参考标志和变换矩阵见authoring.json，来源摘要见source/provenance.json。固定注册没有按alpha包围框缩放或镜像。

重导：`python3 Art/Parts/P1-v1/left/back-scabbard-v1/export.py`。
