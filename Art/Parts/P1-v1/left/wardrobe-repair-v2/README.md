# 向左衣物返修 v2 · 主线程修正

v1被用户判退：绿衣提取丢失轮廓/镶边，灰裤块状拉伸，靴子结构丢失，蓝外套是硬片状下摆。旧版及其原始文件保留，原内部美术通过撤回。

v2用同一r3人体的13姿势作固定4×4控制表，imagegen逐姿势重画绿短衣/灰裤/棕靴与蓝长外套。`source/`保留控制表、两张1254²原始生成表与注册诊断；只提取衣物，生成表上的头、脸、手、身体不替代共同人体。统一全表1024/1254注册，各256格固定切片，不按alpha包围框适配。

`export.py`导出forester、lower、wayfarer三份独立普通pose-map资源。保留原画布料、暗描边与镶边的邻接像素，避免只留绿色/蓝色导致丢线；裤靴分界跟随每姿势画出的靴口，不用横向棕色带涂小腿；后侧原手掌和不透明共同头部独占像素不写入衣物。蓝衣摆保留完整曲线、褶皱与逐帧摆动，不再将原站姿长条缩放成两块硬片。背景红色边缘杂点仅按固定源稿清理规则排除，头部区域不使用。

小范围同材质underlap只补共同身体衣物接缝，隐藏补片限原可见轮廓附近；原人体、关节、动作、头部变换和公共compositor不改。source中的生成表是美术源稿，不是可直接替换身体的整人帧。运行时不按服装ID分支，也没有骨骼系统接入。

需要Python、Pillow、NumPy、SciPy。运行 `python Art/Parts/P1-v1/left/wardrobe-repair-v2/export.py`；三个子包各含原稿快照、authoring、PNG和分层ORA/SVG。源导出须与同一r3模板一同保留。[实际合成审核](../../../../Review/P1/modular-left-wardrobe-v2/README.md)。当前新外观artApproval=null，仅覆盖left的13既有姿势。
