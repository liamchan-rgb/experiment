# 随机地图节点建筑 v1

四张512×512透明PNG：战斗木寨/红棚、首领紫晶石门、奖励绿棚/宝箱、空地水井/路标。起点复用既有CampTent。建筑资产和nodeID绑定，点击建筑仍前往关联的实际道路节点，不额外创建战斗或奖励。

使用图像生成工具创作并二次修整，原图保留在source；并非用户提供/已认可美术。导入器scripts/import-meadow-landmarks.py统一四象限画布尺寸，固定缩放480/627与16px留边；针对模型留下的鲜红色透明边缘污染，仅在5px Alpha边界邻域用邻近有效材质色去污染，并删除少于9px孤立分量/清除Alpha0 RGB。暗红棚布保留。数量与摘要见assets.json。不是重新生成/更改人体、衣装或动作。

运行时宽度：战斗90、首领104、奖励86、空地74，脚底锚点0.08；无风摆。与既有建筑一样通过透明剪影参与Metal投影。主线程检查整张图与实际地图比例、透明边缘及节点/道路避让。新美术用户认可为null。
