# 项目原生分层 · 猎弓第一关键帧 r2

针对用户指出的连接点、背心外露、拉弦袖被拉扯和持弓臂覆盖躯干问题返修，仍只制作这一张关键帧。

- 近侧肩部回到原项目角色的 (117,141)，上臂与前臂拆层；上臂接入外套下面，前臂按折叠姿势在前。
- 远侧持弓臂排在躯干外套之后，肩根由外套覆盖，伸出的袖子接腕部。
- 躯干外套面补齐；头部裁片改为头颈遮罩，去除矩形裁片带出的打底背心，不重画脸或头发。
- 拉弦侧袖子沿肘到腕方向收束，短袖口与手部重叠接合，不再把一块下垂袖片拉到胸前。

独立原生图层：farArm.png、nearUpperArm.png、nearForeArm.png、torso.png（均 256×256）；drawing-hand.png（16×12）、grip-hand.png（14×12）。pose.json 保持 BowRigSample 数据结构；assembly.json 明确本帧合成顺序、头部遮罩对应脚本、素材来源和指尖/弓柄接触点。

复现：`python scripts/review-bow-aim-project-r2.py`。assembled.png 是原生透明合成，审核目录提供原尺寸和整身 3 倍图。本轮调整了关键帧审核合成的层序和遮罩；尚未把这些改动迁移到运行时连续动画，不代表已完成换装所有动作。待用户审核，不生成整图、不打新 IPA、不运行 App/模拟器/实机、不使用智能体。
