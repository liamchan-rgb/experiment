# Blue eye and right-facing features · battle idle candidate v3

This revision moves the eye, brow, nose and mouth several pixels inward from the profile edge, strengthens the blue eye against the skin, and keeps the mouth closed. `face.svg` is the editable integer-pixel source and `face.png` is the transparent 256×256 feature-only export. It contains no skin, ear, or hair pixels.

The exact alpha bounding box is `[140, 105, 152, 120]` in `(left, top, right-exclusive, bottom-exclusive)` convention. See the [r2 overlay with separate hair](review-r2-with-hair.png) and [enlarged head detail](review-head-detail.png). This is still one unapproved static candidate, with no other directions or production compatibility.
