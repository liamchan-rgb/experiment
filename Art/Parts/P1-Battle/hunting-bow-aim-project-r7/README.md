# 猎弓第一关键帧 r7 · 固定肩根，略缩双臂

用户要求保持两条手臂现在的连接处，缩短一点。本轮近侧肩根仍为 (117,141)，远侧肩根仍为 (138,148)；以各自肩根为固定点，将水平伸出长度收短约 10%，保持袖层高度、近/远遮挡及弯曲姿势。双手原生 PNG 不缩放、不重画，随臂端移动；弓随持弓手向左 5 个原生像素，弦和箭尾仍接拉弦指尖。

torso.png、全部躯干多边形和腰部最终合成像素与 r6 相同；脸/发和腿/靴保持。原生袖层、坐标和 BowRigSample 格式的 pose.json 位于本目录，固定肩点、缩短比例和弓平移记录在 authoring.json。

复现：`python scripts/author-bow-arms-r7.py`，再 `python scripts/review-bow-aim-project-r7.py`。输出透明 assembled.png 以及原尺寸和整身 3 倍图。主线程查看整身/原尺寸，并检查两个袖口与手部有重叠接合，记录不能替代用户美术审核。
