用户明确“基于这个做后面的动作帧”，以 hunting-bow-aim-project-r7 为选定首帧。首个原生合成与 r7 完全相同；从松弦、箭离弦到近侧手 0.32 秒收回，再将远侧持弓手/弓缓慢放低并停稳。

## 原生结构

- 85 个 20ms 采样帧，总计 1.70 秒，包括开头和收势停留；并非声称补画 85 个独立人物姿势。
- 部件采用连续关节角度作刚性变换，肩根固定、两段臂长保持。近侧手随前臂转腕，远侧握弓手与弓一同转动；两手分工和前后层次沿用 r7。
- 每帧 frames/000..084 含 nearUpperArm.png、nearForeArm.png、farArm.png、完整 BowRigSample 格式 pose.json，以及透明 assembled.png。
- torso.png、握弓手与三种拉弦手形（勾弦、松指、放松）为共享原生图层。弓继续复用项目原资源，由每帧 pose.json 驱动；箭飞行几何单独记录在 animation.json。
- body-core-clean.png 只清掉原首帧掌心完全遮住的旧背心边，修复收手后领口露出的残片；首帧原生合成、可见脸/嘴与头发保持。
- animation.json 给出时间、手形、原生姿势文件与箭飞行数据；authoring.json 记录来源、图层顺序与裁片清理要求。

复现：`python scripts/author-bow-followthrough-r7.py`。使用项目原生分层合成器，不调用图像生成。复现脚本会导出原生帧、正常速度 GIF、实际 GIF 解码联系页和验证记录。
