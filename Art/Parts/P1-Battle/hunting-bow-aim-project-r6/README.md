# 猎弓第一关键帧 r6 · 腰带清理与胸口压平

用户指出 r5 腰带仍有混杂像素、胸口凸起。本轮继续只改衣物：

- 腰带、搭扣和浅色衣摆改成一套连续的原生像素结构，不再拼接被旧持剑袖/手遮住的残片。
- 清理大腿衣物裁片上方夹带的旧衣带和衣摆颜色；保留中性的裤腰像素，避免清理后腰部露空。
- 胸口轮廓不再向前鼓出，门襟跟随回收的胸腰线；只转移旧布料的细微像素变化，不再把旧袖子的圆形明暗搬到胸口。

手/双臂的五个 PNG、所有关节和非躯干多边形与 r5 完全相同。最终合成的双手不透明像素不变；脸/发、腿/靴以及衣物范围外像素不变。验证记录在审核目录 validation.json，不能等同于用户美术认可。

原生图层仍是 256×256，衣身/腰带在 torso.png 中，其余手/臂独立。pose.json 为 BowRigSample 数据结构；authoring.json 记录衣料来源，assembly.json 记录层序。腰部旧裁片屏蔽逻辑在审核合成脚本 asset 函数中，后续接入运行时需一起迁移。

复现：先 `python scripts/author-bow-jacket-r6.py`，再 `python scripts/review-bow-aim-project-r6.py`。本轮没有调用图像生成；仍仅一张待审关键帧，不扩展动画、打 IPA 或运行 App/模拟器/实机，不委派智能体。
