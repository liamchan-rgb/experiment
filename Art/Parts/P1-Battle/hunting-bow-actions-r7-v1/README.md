# 猎弓专属状态动作 r7 v1

基于已确认的 r7 原生衣身、连续袖身、手形和猎弓，主线程制作防御、受击、举弓胜利、单膝跪地撑地四项动作。202 个20ms采样姿势，不称202幅独立手绘。复起反向使用同一倒地轨迹；已有143个射击采样不改。每帧的衣身、头、发、脸、两臂、双手和八个腿部层仍分开，武器/弦依各自挂点绘制，运行时不使用 assembled.png 整人帧。

`animation.json`给出四条动作和各帧部件。`canvasBaked`表示部件已在共同256画布上摆好，运行时不能二次应用旧身体倾斜。`rootOffset/groundY/contacts`从原生靴底有效不透明像素测出；不以alpha=1的原素材残边当落地平面。倒地裤脚曾出现地面以下残片，已收回到地面并保持靴子直立；手撑地，弓斜持在前。防御/受击始末与认可站姿整人逐字节一致；胜利/倒地从相同站姿起步，终姿保持。

重建：`python scripts/author-bow-actions-r7.py` → `python scripts/import-reviewed-bow-r7.py`。图集紧密装箱，不增加整人图。状态播放由共用BowRig提供，单人与小队共同调用；小队战斗结束且收势完成后触发胜利，倒地玩家不被胜利覆盖。用户实机复核待定，未扩大此前射击认可。
