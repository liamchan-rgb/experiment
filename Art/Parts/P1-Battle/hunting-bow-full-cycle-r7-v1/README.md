# r7 猎弓完整射击流程 v1

用户“那做吧”授权补齐当前弓的前半段，供同类弓以后复用。本版为项目原生独立分层素材，不是图像生成的完整人物图。

新增 58 个 20ms 采样帧（1.16 秒）：腰前持箭待发、抬弓/搭箭、接弦停顿、继续抬弓与拉弦。初始已拿着箭，本片不包含从箭袋取箭动作。左手握弓，近侧右手搭箭与拉弦；搭箭后，右手指尖/箭尾/弦心始终同点。手掌跟随袖口，袖身使用连续原生层，肩根保持，头脸和衣身源保持。

后接用户已认可 r7 v3 的全部 85 个放箭/收手/放低弓采样帧；这些关节、PNG 和源合成文件逐字节保持。全片 143 个原生采样帧，2.86 秒含停留。动作插值不应描述为人工画了 143 个独立姿势；本轮为原生几何变形与既有独立手形装配。

- animation.json：动作阶段、20ms 时间、每帧 pose/前景袖层与手形、后段箭矢记录。
- authoring.json：真实装配层序、制作来源和可替换弓的挂点名称。
- weapon-binding.json：当前弓的握点、弦点与箭长参考配置；尚未接运行时。
- sleeve-construction.json：搭箭、拉弦的肘部控制点和接弦位置。
- frames/000..142：独立袖层、参考部件、透明人物合成与 pose.json。实际近侧前景使用 nearSleeveConnected.png；不要重复叠加构造参考袖片的描边。
- 共享 torso.png、独立 drawing-hand / grip-hand 和 held/open/relaxed 手形；头/发/脸、腿/靴、当前猎弓 PNG 仍读取原项目资源。

同类弓预留 bow/farHand、上下弦点、弦心/箭尾/箭尖；新弓需要提供自己的握点与弦点配置，本轮仅审核当前猎弓，不宣称其他弓已经测试。身体模组不随更换同类弓重新生成整人图。

复现：`python scripts/author-bow-full-cycle-r7.py`。依赖 r7 首帧、r7 v3 原生构造辅助函数和其已认可后段，不覆盖这些已通过资源。正常 GIF 单次播放，起始手里有箭、结束已射出，不能把两端硬连成循环。

主线程亲自制作并按原尺寸/放大全身、全部实际 GIF 解码画面检查肩肘腕、袖形/衣身遮挡和弦箭接点。修过一次中间稿的弦心滞后问题；技术验证只防回归，不代替美术认可。本轮新前段/整段待用户审核，未接 demo、打 IPA、图像生成、运行 App/模拟器/实机或委派智能体。
