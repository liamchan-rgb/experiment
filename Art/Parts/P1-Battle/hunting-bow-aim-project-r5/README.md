用户指出 r4 衣服仍不够服帖。本轮只调整衣身：收小腋下至腰侧余量，让前襟随胸腰方向收束，按抬臂姿势调整短褶皱；保留原战斗外套的衣料像素、领缘、腰带和衣摆。清掉原裁片中重复的旧前襟，避免与新门襟并排；审核合成不再把旧站姿衣边重复叠到已包含装饰的原生衣身上。

手/双臂 PNG、所有关节和非躯干多边形与 r4 完全相同；最终合成内双手不透明像素也逐点核对一致。脸/发、腿/靴和衣身范围外像素不变，具体见审核目录 validation.json。

复现：`python scripts/author-bow-jacket-r5.py`，然后 `python scripts/review-bow-aim-project-r5.py`。输出仍是原生 256×256 独立衣身和 BowRigSample 格式单帧数据；素材来源及哈希在 authoring.json，合成层序在 assembly.json。
