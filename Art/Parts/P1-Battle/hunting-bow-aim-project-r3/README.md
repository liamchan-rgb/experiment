# 猎弓第一关键帧 r3 · 仅收窄衣服腹部

用户指出 r2 衣服腹部太大，并明确“手不用改”。本轮仅收窄腹部衣料，改平腹部亮色块，清除收腰后露出的旧重复腰带边；双手、双臂图层文件、关节位置与 r2 完全相同。

保留 r2 的肩根、袖口、上/前臂拆层及遮挡顺序。原生 256×256 的 torso.png 与 pose.json 描述本轮衣料；其他 PNG 逐字节沿用 r2。脚本只在旧大腿衣物裁片的腹部范围屏蔽重复腰带边，不改变腿部本身。

复现：`python scripts/review-bow-aim-project-r3.py`。assembled.png 是原生透明合成；审核目录提供原尺寸与整身 3 倍图。逐像素核对变化限定在 x=110..148、y=149..172 的腹部区域，其余整身像素相同。

仅单张待审关键帧；未扩展动画、迁移运行时、调用图像生成或打包，不运行 App/模拟器/实机，不使用智能体。
