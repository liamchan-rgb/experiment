# 猎弓拉满弓第一关键帧 · 项目原生分层候选

本轮直接使用项目 256×256 人物画布、原人物头部/身体/腿部/弓资源与现有合成顺序。没有调用图像生成。仅重新制作近/远侧袖子与袖口、两只手；袖形为 pose.json 中的原生像素多边形，同时导出为透明 PNG。

- nearArm.png / farArm.png：256×256 独立衣袖图层。
- drawing-hand.png：16×12 近侧拉弦手，沿用项目 (-14,-6) 接触点偏移。
- grip-hand.png：14×12 远侧握弓手，沿用项目 (-8,-6) 偏移。
- pose.json：BowRigSample 同结构的本帧姿势、衣袖多边形、弓与双手位置、弦与箭尾接触点。
- assembly.json：项目原素材路径及 SHA256、替换图层与复现命令。
- assembled.png：透明 256×256 完整人物合成。

执行 `python scripts/review-bow-aim-project-r1.py`，使用现有 gear_render 项目审核合成器生成本帧，不依赖上一张生成草图或整张新人物图。头部/身体/腿部/弓等 13 个复用资源已与仓库字节核对一致。

本轮仅第一关键帧资源候选，供用户检查双臂结构。尚未替换运行时连续动作或完成后续关键帧；不打新包、不运行 App/模拟器/实机、不委派智能体。不能据此宣称装备所有动作已经适配或用户美术认可。
