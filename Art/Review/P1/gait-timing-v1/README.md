# P1 步态参数修正 v1 · 离线对照

**离线合成，不是 App/模拟器/实机录像。** 用 `scripts/review-gait-timing.py` 以 `Hero1Directions` 实际图集格、
与 `Sources/Game/WalkCycle.swift`（GaitTiming）和 `HeroBreathing.swift` 相同的公式生成；地面按实际行程速度
（25×3=75 世界点/秒，按投影距离）滚动，用来看脚底是否相对地面打滑。正常速度：20 ms/帧，160 帧＝3.2 秒（10 个完整步态循环）。

- `gait-timing-normal.gif`：左两列为旧均匀时序 / 新按脚底重分配，左、下、右三方向；右列为待机呼吸（2× 放大）。
- `timing.json`：每个朝向 8 个姿势各自占的行走距离（每行合计 24）。

## 改了什么（不改图片、方向绑定、锚点或操作逻辑）

1. **按脚底重分配每个姿势的时长（防滑步）**：原来 8 个姿势各占 3 个距离单位；美术里落地脚每个姿势后移的距离不均（例如向左 +12、−1、+18 像素），
   于是脚先停住再猛滑。现在每个姿势的时长按该姿势落地脚在原图里实际后移的距离分配（夹在平均值的 0.45—1.8 倍，再与均匀混合 60%），
   一个循环仍是 24，仍用同一 24 格时钟，阴影与骨架数据一致。平均每姿势打滑：左/右 1.62→0.80，下 1.62→1.12（距离单位）。
2. **上与四个斜向保持均匀**：这几个方向原图里落地脚一个循环只后移约 5—7 单位（应为 24），靠时序修不了，留给后续按骨骼重烘焙步幅。
3. **待机呼吸**：站定后 0.6 秒渐入，以精灵地面锚点为原点做最多 1.2% 的纵向起伏、周期 3.4 秒，三名成员相位错开；起步/行走/收步 0.15 秒内渐出；
   倒地成员不呼吸；Metal 阴影同步缩放。`-alignmentReview`、`-noBreathing` 时关闭。

起步/收步帧时长（120 ms）与步频（每循环 24 单位）本轮未改：前者会改变点击后开始移动的时间，后者涉及测试常量，均待用户决定。
