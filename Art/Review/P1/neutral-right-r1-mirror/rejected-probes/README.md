first-light-transfer-material-mixing.png：首轮全帧空间取色把部分暖白安全衣当成皮肤，肩与腿出现杂色。

spatial-skin-transfer-patches.png：收紧肤色后，生成参考与原身体轮廓不一致，空间采样仍在小腿产生色块。

主线程拦截并自己修复：头部仅用同一96局部色稿随原headToCanvas投影；四肢采用同一张工具原稿固定近/远肤色盘，按原RGB确定取色，保留原材质轮廓及全部安全衣裤/墨线/alpha，不按每帧参考轮廓贴色。生成参考alpha及新形体不导入。两份失败稿不作为交付。

source-tone-variation-palette.png：仅固定色盘仍会继承旧各帧画稿的深浅差，同一远腿在不同步相偏暗/偏亮。主线程改用同侧共享肤色中值锚定，使所有帧映射同一工具中间色；臂/手共用锚点，既有阴影相对边界保留，alpha和衣物不改。最终近/远腿26份肤色中值分别稳定，无逐帧换肤色。
