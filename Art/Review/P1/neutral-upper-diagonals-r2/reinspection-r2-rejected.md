# r2再次判退后的主线程复查 · 2026-10-23

用户反馈：“还是不行，你自己再检查一下有什么问题，自己描述一下”。本次只复查与描述，不修改美术、动作或安装包。r2内部美术通过/足够交付的结论撤回，原图及有限技术证据保留。

主线程重新检查两方向1×/2×全身、全部八帧及作者动作，确认以下问题：

1. 上身站桩。躯干只有0.25像素幅度上下移动，腰胯/肩带没有转动和重心左右转移，腿在身体下面活动，却缺乏承重过程。
2. 手臂像整块纸片摆动。整条臂手只绕肩旋转，肘角和腕姿不变，没有肘部缓冲与手的跟随，连接在一起并未让动作自然。
3. 腿像软管弯折。逐行横移/纵向映射把膝、小腿和原高光一起拖弯，左上07及右上03/07的膝踝附近可见形体弯曲生硬；固定源和固定骨长不证明轮廓/关节的美术正确。
4. 脚部没有完整步态。代码明确把踝下原足整体平移，缺少落跟、压实、蹬地、脚掌翻转与摆腿收脚；顺序图里脚掌多帧保持同一平板姿态，读起来像挪脚。
5. 交叠难读。左上04–06脚和腿挤在一起，右上01–03脚距也紧；缺少清楚的穿越/摆腿姿势，1×下难持续分辨哪条腿在支撑、哪条在摆动，不能把每次读不清都解释成正常遮挡。
6. 右上双脚朝向与透视不统一。近脚明显朝右，远脚却向相反外侧撇，和身体前进方向不协调；相较于连接问题，这属于源姿态和动作设计本身的问题。
