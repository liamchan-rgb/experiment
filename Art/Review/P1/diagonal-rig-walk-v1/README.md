# P1 斜向行走 · 骨骼重摆（v2：两段腿屈膝）

原四个斜向的 8 帧行走腿几乎不动（双脚位移 1–2 像素），与正向/侧向的步伐不协调。
`scripts/build-p1-diagonal-rig-walk.py` 以每个方向的待机姿势为唯一来源，按部位组变形重做全部 8 帧：

- 腿（身体腿、裤、靴）：大腿、小腿两段，髋随身体起伏，脚沿朝向做支撑/摆动轨迹，步幅 ±11 像素（屏幕 x）；
  触地后承重微屈，蹬地时脚跟抬 3 像素、膝前顶，摆动时脚收到膝后抬 8–9 像素、过渡帧膝盖抬高 7 像素前顶 8 像素（v2，用户反馈 v1 膝盖太硬像在地上挪）；
- 手臂（手臂、袖、手）：与腿反向前后摆 ±5 像素；
- 其余（躯干、外衣、头、背负武器）：整体上下起伏（触地后下沉 2 像素、摆动过渡后升高 1 像素）；脸与头发经 motion.json 的 headToCanvas 同步起伏。

相位约定不变（第 1 帧右脚触地，1–4 右脚支撑，5–8 左脚支撑），起步/收脚帧、待机帧、四个正向未改。
所有使用中的部件（基础身体、下装、两套外衣、皮甲、符文甲、四种背负武器）同规则生成，重新烘焙 30 张斜向图集与头部拆分（复核最大差 1 级、手不压头）。

脚底标记同步更新到 hero-gait.json：斜向每周期支撑脚位移由约 7 提升到 17–20（满分 24），平均滑步 0.48–0.90（原 2.12）。
