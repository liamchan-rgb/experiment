# 原画上皮 · 右下原型 v1（林间绿衣）

用户放弃低模与规则画，要求看“原画上皮”。`scripts/p1-reskin/reskin.py`：
- 躯干、头、五官、头发、背剑：原画像素，只随身体起伏平移；
- 靴子、手：原画像素，随脚踝/手腕平移，不旋转不缩放；
- 大腿、小腿、上臂、前臂：骨骼以原画待机关节为准（用模型深度抬到 3D），按认可的小跑姿势用 IK 重新摆位；
  每个输出像素找到它在肢体上的点，按该肢段的旋转映射回待机姿势，到原画同一位置取色（裤子只用裤子像素，避免小腿与靴子间露肤色），
  肢体粗细按原画实测宽度，重摆后补 1 像素描边。

原画来源：git 527e3548 的原始分层部件（`Art/Parts/P1-v1/eight-way-v1/*`、motion.json），通过 `git archive` 取出后作为参数传入。
- `down-right-all-cells.png`：三行分别为原画、低模 v3、原画上皮；13 列为待机、起步 1-2、小跑 1-8、收脚 1-2；
- `down-right-slow.gif`（120 ms/帧）、`down-right-game-speed.gif`（40 ms/帧，游戏实际节奏，新版地面按真实速度滚动）。

待机帧与原画相差 445 像素（四肢按原画宽度重画后轮廓的细微差别）。未接入游戏。
