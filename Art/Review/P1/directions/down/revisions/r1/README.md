## 本版改动

逐姿势重新绘制前向鞋面、靴筒和屈膝，不再由旧站姿的鞋掌固定旋转和平移生成。重画的站姿也采用这套靴子；摆腿末段另做一轮修订，减弱鞋底朝镜头的过度透视。双臂随左右腿变化，配合小幅重心和身体上下位置变化。

完整整表试画在动作顺序上不够连贯，没有作为最终候选；本版采用逐姿势绘制的源 PNG。`raw/` 保存各张完整源图，`frames/` 保存装入 256 × 256 画布后的序列。导出工具按头部标记对整个人物等比缩放与定位，不对鞋或腿单独拉伸，不生成插值动作；过程见 `generation.json` 与 `packing.json`。编号预览只增加排版、黑底和文字。

循环只播放 01–08，不把站姿混入步行循环；正常每姿势 120 ms，完整周期 960 ms，慢速每姿势 480 ms，周期 3840 ms。可先正常播放看整体，再用编号图检查鞋尖、靴筒体积、裤腿、过腿以及双臂配合。
