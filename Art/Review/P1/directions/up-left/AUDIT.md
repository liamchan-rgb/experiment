# P1 左上 ↖ 修改依据

用户认可左下 r1 后要求修改下一组；按斜向行序进入左上。

原版只从站姿派生腿部，背部与双臂近乎固定；后摆鞋踝和鞋底方向、过腿遮挡、站姿至步行的靴子体积需要重画。新稿固定三分之四背面左上视角，头、胸、髋与鞋尖一致向左上；不画成正背面或纯左侧面。

以已认可向上 r1 的背部、翻边靴和抬跟为设计参照，已认可左下 r1 为相位、短步幅与节奏参照。逐张画 00 新站姿及 01–08 两步循环，包含两次承重、过腿、摆腿末段和反向摆臂。完整姿势绘制后统一缩放定位，不单独扭鞋或拉伸小腿。

人物解剖左／右与画面近／远分开说明；本轮按画面近侧／远侧描述相位，解剖侧编号留给模板统一。包袋固定侧挂点及装备替换留给分层模板，正式足底、阴影和转向相位仍需接入时统一。仅制作当前方向审核稿，用户确认前不推进右上。
