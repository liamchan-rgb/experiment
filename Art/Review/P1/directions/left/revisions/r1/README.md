## 编号与动作

00 是新站姿，01–08 是两步循环的八张重画关键姿势，不对应旧版 24 帧编号。近侧为人物左腿／左臂，远侧为右腿／右臂；八张行走图均为独立姿势，不用镜像、变形或重复凑帧。

| 帧 | 动作 | 主要观察点 |
| --- | --- | --- |
| 00 | 站姿 | 靴筒、鞋头与行走稿属于同套设计 |
| 01 | 近腿向前落脚 | 近臂向后，后脚鞋尖仍朝左 |
| 02 | 近腿承重 | 远腿弯膝离地，靴子保留完整体积 |
| 03 | 远腿过腿 | 远膝向前，抬脚经过支撑腿旁，近胫遮住远靴部分轮廓 |
| 04 | 远腿摆腿末段 | 近臂向前，远脚低位伸出，近脚后摆抬跟 |
| 05 | 远腿向前落脚 | 近腿在后、近臂在前，区别于 01 的遮挡与摆臂 |
| 06 | 远腿承重 | 近腿弯膝抬脚，近靴在前景，鞋头保持朝左 |

| 08 | 近腿摆腿末段 | 近臂向后，衔接下一循环 01 |

## 修改与导出

使用图像生成工具逐姿势重画，保留棕发、蓝眼、蓝围巾／外套、腰包、翻边系带棕靴。已认可的向下 r1 提供外形和靴子设计参考，原向左站姿提供视角参考。重点修订后摆鞋尖翻转、鞋踝接缝、过腿收拢及近远腿／摆臂交替；03 过腿初稿和 04–06 的另一半摆臂另作修订。提示词与所选源图记录在 [generation.json](generation.json)，所选原图保存在 `raw/00.png`–`raw/08.png`。

`scripts/package-character-review.py` 只对完整人物等比缩放和定位，未单独变形鞋腿。向左使用 [registration.json](registration.json) 声明整体轮廓高度与脚底轮廓参考线，控制站姿／行走的整体大小和 2–3 像素起伏。脚底轮廓线用于原地预览，不冒充正式游戏的物理接触点；具体足底、阴影、地图内移动和启停仍需接入后另验。默认头部注册方式保持兼容已认可的向下稿。

正常循环每张姿势 120 ms，共 960 ms；慢速每张 480 ms，共 3840 ms，只播放 01–08。编号图按从左到右、从上到下读取，GIF 为黑底两倍最近邻预览。导出一致性、GIF 解码、默认导出回归结果见 [validation.json](validation.json)；这些检查不代表动作美术通过。
