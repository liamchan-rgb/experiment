## 与向左稿的对应关系

00 是新站姿，01–08 是两步循环八张关键姿势，不对应旧版 24 帧编号。以已获认可的向左 r1 每张对应姿势为直接参照，用图像生成工具逐张制作向右对应稿。初稿的过腿、近远腿遮挡和步幅未完全对应，进一步以完整姿势反向参照修订全部行走稿，保留原来膝踝形状、近远明暗、抬脚高度和相反摆臂；未通过导出脚本变形鞋腿来匹配。

两方向均使用 256 × 256 单格、相同的轮廓高度序列和脚底轮廓参考线、每关键姿势 120 ms 的正常节奏。近／远腿阶段对应如下：

| 帧 | 两方向共同阶段 | 向右观察点 |
| --- | --- | --- |
| 00 | 站姿 | 完整靴筒、双鞋尖朝右、靴子体积与向左呼应 |
| 01 | 近腿向前落脚 | 近臂后摆；远脚在后，鞋尖仍朝右 |
| 02 | 近腿承重 | 远腿弯膝离地，保持靴子体积 |
| 03 | 远腿过腿 | 收拢于支撑腿旁，近胫遮住远靴部分轮廓 |
| 04 | 远腿摆腿末段 | 近臂向前跨过上衣，远脚低位伸出 |
| 05 | 远腿向前落脚 | 近腿在后且位于前景，近臂向前 |
| 06 | 远腿承重 | 近腿弯膝抬脚、近靴位于前景 |
| 07 | 近腿过腿 | 近靴在前景收拢，避免初稿步子偏开 |
| 08 | 近腿摆腿末段 | 近臂后摆，衔接下一循环 01 |

向左的近腿是人物左腿，向右的近腿是人物右腿。因此同编号是观看侧的近／远相位对应，不表示同一解剖腿编号；正式变向相位和非对称装备挂点尚需模板接入时统一，当前不将对应稿冒充完成分层模板。

## 文件与导出

所选绘图源 PNG 在 `raw/00.png`–`raw/08.png` 原样保留，参考图、提示词、初稿与修订来源见 [generation.json](generation.json)。已认可向左文件只作为参照，不改动其像素。

`scripts/package-character-review.py` 配合 [registration.json](registration.json) 对完整姿势统一缩放定位；配置与向左 r1 一致。脚底轮廓线 y=224 是原地预览参考，不是正式游戏物理接触／阴影数据。

新增 `scripts/package-character-pair-review.py` 复现逐姿势与同步对照：每组左侧标注 `LEFT r1 APPROVED`，右侧标注 `RIGHT r1 REVIEW`。对照导出阶段仅给两套原帧加黑底、编号并最近邻放大，没有反转、变形或改色。同步循环不含站姿；正常八帧每帧 120 ms、周期 960 ms，慢速每帧 480 ms、周期 3840 ms。来源与配对记录见 [pairing.json](pairing.json)，导出核对及尺度观察见 [validation.json](validation.json)。这些检查不代替用户美术认可。

以 256 × 256 单格为单位，左右对应帧的头部边界高度最多相差 1 像素，y≥180 的下部棕色靴轮廓总横向范围最多相差 3 像素，详情见 [coordination.json](coordination.json)。后者包含步幅与鞋形投影，只作协调检查辅助，不是实体鞋尺寸，也不作为美术通过标准。

认可范围为本稿新站姿、八张关键姿势和已展示的左右协调对照，作为向右方向模板依据；四个正交方向 r1 现均已认可，当前开始右下 ↘ 审核。生成、排版、协调及验证 JSON 保留生成／检查当时的未认可快照，后续认可单独记录于 `approval.json` 与总状态。正式图集、运行代码、足底／阴影、IPA 与最终分层换装模板均未替换。
