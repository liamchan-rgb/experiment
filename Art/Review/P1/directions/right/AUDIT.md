# P1 向右：鞋踝与左右协调修改依据

2026-10-18，用户反馈：“对的，开始修，确保和刚才修好的向左走的观感能互相呼应协调”。据此修正后摆脚鞋尖翻向左、双脚交会时鞋形挤压和上身／手臂基本固定的问题；另以已认可向左 r1 为逐姿势对照，统一左右两方向的比例和运动节奏。该意见为修改授权，向右尚未获认可。

## 绘制与对照约束

- 以向左 r1 的 00–08 所选完整姿势为对应参考，逐张绘制向右稿。保留同一人物外形、服装配色、头身比、完整翻边系带棕靴、正常短步幅与相反摆臂。
- 双靴鞋尖都朝屏幕右方，后摆时通过膝盖、脚踝、抬跟和趾部弯折表现；不将后脚整只鞋翻向左。
- 两次过腿均收拢到支撑腿旁，保持靴子体积、鞋腿接缝及前后遮挡；近腿／远腿交替，不把同一条腿反复迈出。
- 左右对照按观看侧的近／远腿阶段一一配对：01 近腿向前，05 远腿向前，03／07 为相应过腿。向右近侧为人物右腿／右臂，向左近侧为人物左腿／左臂；同帧对照是视角相位对应，不是同一解剖腿编号。正式运行的变向相位与装备挂点需接入模板时另作统一。
- 复用向左 r1 的画布、轮廓高度序列、脚底轮廓参考线与 120/480 ms 关键帧时长，另导出左右同步循环和逐姿势对照。保留向左已认可文件，不为匹配新稿修改旧稿。

## 版本与范围

向右 r1 另存新站姿和八张关键姿势，00–08 与原 build 28 的 00–24 不同。图像生成工具绘制，导出脚本只对完整人物统一缩放定位、排版和组帧，不单独变形鞋腿；左右协调仍需用户美术审核。正式图集、足底／阴影、IPA 和最终分层模板未接入本候选。
