## 编号与动作

固定朝左下的三分之四正面视角，近侧为角色左侧，远侧为右侧。头、胸、髋及双鞋尖沿 ↙，不是纯左侧面或纯正面。00 为新站姿，01–08 为八张独立关键姿势，与原版 00–24 编号不对应。

| 帧 | 动作 | 主要观察点 |
| --- | --- | --- |
| 00 | 斜向站姿 | 双靴同向，翻边和靴子体积与走路协调 |
| 01 | 近侧左腿向前落脚 | 前脚朝左下，右后脚抬跟，左臂后摆 |
| 02 | 左腿承重 | 右膝弯曲、后脚开始回收 |
| 03 | 右腿过腿 | 右靴收至支撑踝旁，部分被近胫遮挡 |
| 04 | 右腿摆腿末段 | 右脚低位向左下伸出，左臂前摆 |
| 05 | 右腿向前落脚 | 左腿在后、左臂在前，交换支撑腿 |
| 06 | 右腿承重 | 左膝弯曲回收，保留完整靴筒 |
| 07 | 左腿过腿 | 左靴从前景经过支撑踝旁，两脚收拢 |
| 08 | 左腿摆腿末段 | 左脚低位伸出，左臂后摆，衔接 01 |

## 来源与协调依据

图像工具以已认可右下 r1 的 00–08 每张完整姿势为参考，绘制朝左下的对应姿势，保留同相位的膝踝弯曲、近远遮挡、反向摆臂、短步幅与靴子设计。不是把旧站姿鞋尖沿用到行走，也不将鞋子切下旋转或缩小。

所选源 PNG 原样保存在 raw/00.png–raw/08.png，提示词、参考图与 SHA256 见 [generation.json](generation.json)。旧版固定切片与认可右下文件均保留；修改约束、观察侧／解剖侧区别及未来非对称装备要求见 [AUDIT.md](../../AUDIT.md)。当前完整人物左右对应会交换包袋所在侧；固定侧装备与可更换装备仍需后续分层模板处理。

## 导出与验证

复用 scripts/package-character-review.py，仅统一缩放、定位完整人物与排版。注册配置与右下 r1 逐字节一致，单格 256 × 256；脚底轮廓线用于原地预览，并非正式物理足底或阴影挂点。没有单独缩放鞋腿、补帧或肢体变形。

正常循环 01–08 每帧 120 ms，周期 960 ms；慢速每帧 480 ms，周期 3840 ms。编号图从左到右、从上到下读取，GIF 为两倍最近邻黑底预览。文件检查和重新导出结果见 [validation.json](validation.json)；美术自然度与连续观感留待用户认可。

本轮只提交左下 r1；左上／右上未重画。正式图集、运行代码、IPA 与最终分层换装模板尚未更新。
