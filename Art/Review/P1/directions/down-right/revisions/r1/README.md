## 编号与朝向

00 是新站姿，01–08 是完整两步循环的八张独立绘制关键姿势，与旧版 00–24 帧号不对应。固定三分之四正面右下视角：头、胸、髋与双鞋尖均朝 ↘，看到两只眼及前胸与近侧；角色右侧为近侧，左侧为远侧，不能把本稿当成单纯向右侧面或向下正面。

## 绘制依据与来源

原右下站姿提供斜向视角参照，已认可向下／向右 r1 提供相同人物、服装和靴子设计。先绘制新右下站姿，再以该模型及相邻两方向的同相位关键姿势逐张画右下动作，保持头身比、正常短步幅和反向摆臂，不将正面或侧面鞋图切贴旋转。

初稿 03 抬脚仍偏后，03／07 另修两次过腿；01、04、05、08 的前脚鞋底／纵深偏夸张，另行收紧步幅、减小鞋底朝镜头的角度并匹配站姿靴子体积。姿势自然度、斜向一致性和连续播放仍待用户审核。

所选源图在 `raw/00.png`–`raw/08.png` 原样保留；参考图、提示词、初稿、修订来源与摘要记录于 [generation.json](generation.json)。[问题与约束](../../AUDIT.md)及[四斜向固定基线](../../../../02-diagonal-atlas/README.md)独立保留。
