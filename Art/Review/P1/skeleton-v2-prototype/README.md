# P1 骨骼 v2 · 右下原型（小跑）

用户决定：正左/正右（及正下）用现有美术切片即可；正上和四个斜向需完全重做模组。本原型先做右下。

## 关键发现：游戏速度要求小跑而不是走路
P1 实际移动 75 点/秒（reviewSpeed 25 × movementSpeedMultiplier 3），每 24 单位一个步伐周期，
即每个姿势约 40 ms、每一步在地面上要前进约 48 像素（画布像素），而腿长约 35 像素。
走路姿态无论怎么画都会“在地上挪”；本原型改为带腾空的小跑：每只脚只在半个步长内着地，脚底可以完全钉住。
若更想要走路，需要把移动速度调慢（逻辑改动，由用户决定）。

## 做法（`scripts/p1-skeleton-v2/`）
- `skel.py`：RotSprite 旋转（Scale2x×3 放大 8 倍后旋转再采样），地面平面两段 IK（髋-膝-踝，膝向前弯），按 (x, z/2 − 高度) 投影到屏幕，3/4 视角下伸向镜头的腿自然显长。
- `anim.py`：重绘步骤给腿、手臂、外衣轮廓补描边（手臂压在同色外衣上也能看清），膝/肘加关节盖；8 姿势小跑：触地、下沉、蹬地、腾空 ×2，
  身体起伏 ±2 像素，手臂弯曲前后摆。
- `review.py`：生成本目录的 GIF（左：现在游戏里的版本；右：新原型；地面格子按真实速度滚动，用来判断脚是否打滑）。

- `down-right-game-speed.gif`：游戏真实速度（40 ms/姿势）；
- `down-right-slow.gif`：放慢 3 倍看细节；
- `down-right-poses.png`：8 个姿势。

本原型未接入游戏，不影响现有图集。
