# B5 星辉甲／龙纹甲人工美术复核

## 审核范围

- 主线程逐方向检查两套完整人物，查看器以整身1×与2×的13姿势页复核：站姿、八帧循环、两帧起步、两帧收步。
- 重点检查头身比例是否被服装资源改变、肩口和袖口连续、袖甲与手腕贴合、胸甲对躯干覆盖、分片裙甲与裤子之间的边界、两侧手臂与身体近远层次、靴裤运动，以及行走时衣物有没有闪动或漏出底层背心。
- 默认预览使用棕发、蓝眼及既有背剑。另查看两种发色、两种五官、背剑开关的整身矩阵；项目中不含重复衣物槽位。
- 正常速度GIF从实际新catalog和当前motion合成。所有16个步行GIF逐帧解码，合计128帧；8方向各8帧、每帧120 ms、循环960 ms。16个起停GIF也逐帧解码，合计352帧；帧时序为480 ms站姿＋20×120 ms移动姿势＋480 ms站姿。

## 复核结论

星辉甲与龙纹甲分别保持深靛银色星饰结构和酒红铜边鳞甲结构，胸部/肩袖/护腰分区在五个投影视角中连续；三片护腰不会连成一整块遮住腿，袖口不伸进手部。实装帧只由衣物层响应原身体动作，未新增外观专属变换。已确认正下、斜下、左右、斜上、正上方向外轮廓一致，帧间无材质闪白。背剑开启时仍沿原右肩至左髋路径通过背甲表面；空背组合不会残留剑。

星辉甲第一版大片纯白胸甲过于接近现有符文甲，已改为深靛蓝主材、银蓝护边和较小星芒胸饰，并重新输出完整104绑定与复核页。修改只涉及本套源SVG及其新绑定PNG，没有写入符文甲或其他旧资源。
