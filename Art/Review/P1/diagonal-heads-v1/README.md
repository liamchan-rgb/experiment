## 改了什么

1. **斜向眼睛**（左下、右下；蓝眼、琥珀眼两种眼型）：原来近侧眼只有 3—5 行高、像眯眼，远侧眼是 3—4 像素的深色小团。
   现以正面认可的眼睛为模板重建：近侧眼取正面同侧眼，去掉外侧眼线一列和一列虹膜，10 列放在 x 43—52、y 52—59；
   远侧眼取外眼角、眼白、高光、两列虹膜、内眼线共 6 列，放在 x 34—39、y 51—58；两眼间隔 3 像素。右下为左下的精确镜像（与原做法一致）。
   眉毛已是眼睛上方两行的细线，未改。全部在部件规范的五官区域内（合成器校验通过）。
2. **银发斜向颜色**：四个斜向比正面/背面/侧面暗且偏色（前斜偏蓝灰、后斜偏红棕）。按亮度排名映射到同一发型正面/背面/侧面的色阶，
   保留明暗结构。栗发各方向一致，未改。
3. 重新烘焙 60 张 P1 地图图集并重跑头部拆分（复核：最大差 1 个色阶、997 像素、手不压头）。
