# P1 模型 v3（从零重画的身体与衣服，八方向小跑）

用户要求：正上与斜向不再从旧图切割修补，身体和衣服完全重做；之后“可以的，把其余的做出来”。
为保证八个方向动作与画风一致，正左/正右/正下也用同一模型重画（原切片方案替换；如需保留旧正左右可单独换回）。

## 做法（`scripts/p1-model-v3/`）
- `model.py`：有符号距离场低模 Q 版人，按游戏斜俯视投影（屏幕 x = X，y = 地面 − Y + Z/2）逐像素光线步进，原始分辨率直接出像素图；
  5 阶块面明暗、金属高光、贴身接触阴影（只来自同一状态必然存在的部件），外轮廓与前后遮挡 1 像素描边。没有任何位图旋转或拉伸。
- `outfits.py`：按原部件槽位出图——身体（皮肤躯干/手臂/腿/拳头）、裤靴（裤、带鞋口鞋底鞋带的靴）、
  林间绿衣、流浪者长外套（前开衩下摆、浅色立领）、皮甲（皮背心、交叉皮带、护肩、分片裙甲、白短袖、护腕）、
  符文甲（银胸甲、金边、紫宝石、护肩、蓝袖与银护腕、前后蓝色前襟）。
- `clips.py`：待机、起步 2 帧、小跑 8 帧（脚底钉地：着地脚每姿势后退 12 地面像素 = 游戏每周期 24 单位）、收脚 2 帧。
- `scene.py`：各槽位独立绘制后按重叠区深度拓扑排序得到每帧绘制顺序；头部、五官、发型和背负武器沿用已认可的原像素，随脖子平移。
- `bake.py`：八方向 × 13 格写回所有使用中部件的 pose-map PNG，更新 motion.json（头挂点、绘制顺序、关节、脚底）、
  hero-gait.json（阴影脚底、起步接小跑第 1 姿势、`timing: uniform`）。原头部/武器/待机数据首次快照在
  `Art/Integration/P1-model-v3/reference/`，重复运行结果相同。之后运行 `rebake-p1-map-atlases.py` 和 `build-p1-head-split.py`。
