# P1 模型 v3 · 右下小跑（从零重画）

用户要求：正上与四个斜向的身体和衣服不再从旧图切割修补，完全重做。

做法（`scripts/p1-model-v3/`）：
- `model.py`：用有符号距离场搭一个低模 3D Q 版人（躯干、立领、四肢、拳头、靴子），按游戏的斜俯视投影
  （屏幕 x = X，屏幕 y = 地面 − Y + Z/2）逐像素光线步进，直接在原始分辨率出像素图；
  5 阶块面明暗，配色取自现有外衣/裤子/靴子/皮肤，外轮廓与前后遮挡处 1 像素深色描边。
  每帧都是重新绘制的，没有任何位图旋转或拉伸，所以鞋子、手不会扭曲。
- `body.py`：骨骼（髋-膝-踝两段 IK、肩-肘-腕）与林间绿衣：外衣（门襟金边、腰带金扣、下摆金边）、立领、
  袖子金袖口、灰裤、棕靴（鞋口、鞋底）。比例对齐现有正下/正侧待机图。
- `jog.py`：8 姿势小跑（触地、下沉、蹬地、腾空 ×2），身体起伏、前倾、肩胯反向扭转、弯臂前后摆，脚尖随步态俯仰；
  头部暂用现有已认可的头像素（挂在模型脖子上），保证五官自定义不受影响。
- `compare.py`：与现有待机图并排对比比例。

- `down-right-game-speed.gif`：游戏真实速度（40 ms/姿势），地面格子按真实速度滚动；
- `down-right-slow.gif`：放慢 3 倍；
- `down-right-poses.png`：8 个姿势。
