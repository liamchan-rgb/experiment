营地 P1 武器选择传奇权杖。两衣装各104格背负挂载；单人与小队共用独立杖身、关节与法球采样。施法241个曲线采样沿用已认可B2离线动作，按现有1.048秒命中、0.1秒停顿、1.70秒动作窗口映射；出手约0.8384秒，从实际变换后的杖头宝石出发，以40像素拱高弧线命中怪物原生(94,152)的可见部位。保持原骰子确认/停止/结果、菱形AP、血条和死亡隐条。

小队原规则普攻1D20，强击仍1D6+2。自然20由原核心回执判定，立即击杀，爆发扩大并显示“自然20”；不以固定加值凑20冒充自然20。旧单人仍为固定5伤演练，只接新外观/动作/效果，不声称正式规则迁移。

蓝白杖头聚光、轨迹、扩散十字光与弧圈、受击点/地面反光、落地反弹粒子使用同一纯Swift采样；蓝色碎光在动作窗口结束前淡出，避免切换动作突然截断。原受击/死亡金色粒子保留，与冷色魔法叠加。非攻击仍为共用身体状态与护脸腕角，不称新制作完整倒地或全套专属动作。战斗衣装仍为原共用蓝衣，不等于已经完成护甲/外观自由混搭。
