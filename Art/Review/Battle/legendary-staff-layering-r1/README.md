# Build60 权杖首帧遮挡修正

[正常整身动图](body-normal.gif) · [战斗动图](battle-normal.gif) · [站姿](body-standing.png) · [首帧前后对照](first-frame-comparison.png) · [六状态](all-clips-1x.png)

用户指出Build59第一帧法杖与腿错位，撤回那部分内部美术通过结论。原因是idle沿用武器在人物后面的旧层序，杖杆被裤腿切断，下端宝石像悬空；起手又改到前景。现在权杖全部状态读取同一layerOrder，杖杆在腿前、持握手在杖前；阴影与离线审核也用这份层序。同时统一关节补底在idle/施法中的显隐，消除髋部8个像素的起止差异。待机、attack0、attack1整人RGBA相同，原关节曲线/时序、武器图案和玩法保持。

主线程亲看首帧1×/放大全身、六状态30姿势1×/2×、两只正常GIF全部380个实际解码帧20页。对照左图直接取已经交付的Build59站姿像素，原版本可按旧commit查看。离线使用原生产Swift姿态/效果采样及新的共用层序，不是UIKit/实机录屏，地图与光照近似；新美术待用户反馈。没有App/模拟器/设备运行，没有智能体或整人图片生成。

128纯测试/五旧检查、设备Release 40721530191与包校验通过，Mac/Linux九组导出一致；包内新层序JSON逐字节匹配。后两项仍为皮甲/符文甲装备与战斗挂载；力量徽章/行动戒指装备槽与属性反馈。
