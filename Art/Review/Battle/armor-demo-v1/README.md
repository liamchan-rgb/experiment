短剑、猎弓、重剑、权杖同屏比较。复用 r4 皮甲／r5 符文甲的原生独立衣片；通用骨架新增独立护肩，按原 r4 的有限随动角度挂载。新猎弓沿用已认可的手／肘／肩、轮廓和345原生采样，另用原胸甲纹样映射到持弓胸部的衣片内部，衣袖材质分离；不把旧通用袖口强套过去。持弓款保留既有合身袖形及较短衣摆，不声称与通用甲同轮廓。头脸、手、武器、骨架及时钟不改。原蓝衣没有装备护甲时仍保留。

主线程亲看240六状态全身姿势、416八向衣装姿势、四整身GIF462实际解码帧、场景190实际解码帧和四行走GIF32帧；另看持弓／权杖放大全身。状态合集将防御／受击／胜利／倒地各按原时长顺次展示，是剪辑比较，不是状态之间的连续玩法。短剑、重剑、权杖仍复用原通用身体状态，不冒称新制完整倒地。战斗仍是原共用头脸，行走两外观不等于完整战斗外观混搭。

离线合成读取生产Swift导出的原武器姿态和当前衣片映射，不是UIKit／设备录屏；场景光影近似。场景回执复用权杖原样本，P1生命上限按符文甲＋8展示，正式规则由132纯测试和原引擎验证，不把合成UI当实机。新美术用户认可null。

营地P1菜单→护甲，可装备／卸下，库存由原.equip处理。小队生命上限、治疗触发与复活骰预览读GameRules.attributes；旧单人演练也读装备后的上限，但仍固定5伤／原加盾练习，没有整套规则迁移。穿上不回血，卸下按原规则截断HP。

当前待Intel设备Release、安装包校验和公开下载复核；不运行App／模拟器／实机，不使用智能体或整人图像生成。后两项：力量徽章／行动戒指装备槽与属性反馈；B2背包装备界面与存档补齐。
