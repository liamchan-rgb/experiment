# 猎弓 A：放箭与收手动作草稿

用户明确要求基于提供的 A 图继续制作后续动作。本草稿以 [A 图](../hunting-bow-pose-concepts-v1/pose-a-balanced.png)为外观与动作参考，保持近侧手拉弦、远侧手持弓：放弦后箭向右离开，近侧手向后跟随并收至腰侧。

[查看正常速度动图](bow-a-followthrough-preview.gif) · [生成的十二个动作姿势](generated-keyframes.png) · [逐个姿势](frames/)

这是根据 A 图生成的衍生姿势，不是原图直接拆分出的可挂载动画：头脸局部使用 A 图稳定，站姿、远侧手及脚的对应区域在预览中保持固定。12 个关键姿势已由主线程在整身尺度检查；用户尚未审核本草稿，不能标记为通过。

GIF 为 362×362、57 帧，每帧 40ms，总时长 2.28 秒。首尾是不同姿势，设置为单次播放以避免循环回跳；刷新页面可重看。编码帧率并不代表设备帧率。这是放箭和收手片段，尚不包含完整的抬弓、搭箭与拉弓过程。

本轮没有改游戏代码或接入 demo，没有打 IPA，也没有运行 app、模拟器或设备。下一步根据用户对动作的反馈修订，再制作和验证可挂载的资源。
