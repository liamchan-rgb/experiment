# 猎弓衣物与既有模组对照

本轮仅比较与记录问题，没有继续改角色。对照了原战斗侧身模组、正右的旅人蓝外套与林地服、斜下及正下的林地服，重点区分姿势遮挡差异与衣服设计/材质丢失。

[原战斗模组与当前猎弓整身对比](whole-body-comparison.png)。两者使用相同 256×256 画布、相同放大倍率；没有局部放大代替全身检查。

当前猎弓衣物的问题：

- 衣领、门襟和浅色包边的设计未完整延续；不应把外套装饰边等同于露出的背心。
- 腰带、衣摆与衣身的分界被简化，服装识别变弱。
- 大面积几何色块缺乏原衣物细密的像素明暗和布料质感，与原头部/裤腿细节不一致。
- 收腹后肩胸到腰部过度直线收尖，缺少外套应有的厚度与自然松量。

后续修正方向：保持用户要求不再调整的手和手臂姿势，以原战斗外套及已完成换装模组为依据，修复躯干衣料、应露出的门襟/包边、腰带和衣摆关系；保持遮挡正确，不能硬把被手臂遮住的领口画到手臂前面。用户本轮要求先比较，未在本轮制作新候选、动画或 IPA。
