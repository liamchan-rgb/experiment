# 猎弓战斗姿势：三版静态概念图

用户指出 build54 的持弓手与拉弓手角色弄反、姿态怪异且有杂色像素，要求先看几版效果图。原版持弓修复视为用户判退，不以接触像素统计、测试或构建通过替代美术认可。

本轮对右向侧身的理解：**靠镜头一侧的手向后拉弦，另一侧手向前握弓**；拉弦肘朝人物身后，拉弦手接近嘴角，箭尾及上下弓弦汇在该手位置，箭向右、前方手握住弓柄。

- A：轻微屈膝、较均衡。
- B：站距更宽、前膝更低。
- C：站姿更直、拉弦肘稍高。

三图由图像生成工具基于现有角色与姿势示意制作，仅用于比较整体姿势，不是游戏的原始像素图、可挂载图层或动画。图中衣物装饰、色阶和部分边缘与原资源并不完全一致；选定姿势后须基于游戏原人物重做袖口、手、弓和像素边界，检查背景杂点及前后遮挡。三版交付后，用户“那你按a来做”选择 A 作为制作依据，见 user-selection.json；只认可姿势概念，不等于后续像素动作或 build54 已通过。该概念轮未修改游戏逻辑、未制作 IPA、未运行 App/模拟器/实机。
