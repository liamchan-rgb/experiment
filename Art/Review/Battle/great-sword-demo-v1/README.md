在营地 P1 武器菜单选择重剑，进入林地战斗。单人与小队使用同一独立武器层和关节曲线，挥击复用用户已认可的重剑离线源；新增原地预备、短跳贴近、接触停顿、回跳收势的正式时钟映射。小队原规则普攻1D12、强击仍1D6+2，选择时锁骰一次，1.048秒一次结算；单人仍为原固定5伤的演练，未将其虚称迁移正式规则。

剑尖、伤害数字、命中/致死粒子共享位于怪物原生(94,152)的接触点，八个怪物动作均为可见像素。主线程拦下了通用防御/受击/胜利把宽剑遮在脸上的版本，仅调整腕部及剑的朝向；挥击源曲线和原武器材质保持。非攻击状态复用原共用身体模组，不虚称新制作一整套倒地。

离线合成使用生产Swift姿势和真实规则回执，非UIKit、App或实机录屏，场景光照为近似。主线程亲看整身原尺寸/放大、208背负绑定、最终战斗及整身GIF实际解码帧。机械几何测试不能代替美术审核，新运行时美术待用户设备反馈。无智能体，无整人图片生成。

后两项：传奇权杖施法/投射与反馈接入；皮甲和符文甲装备切换、战斗挂载接入。
