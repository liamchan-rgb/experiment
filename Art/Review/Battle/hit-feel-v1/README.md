# 战斗打击感 · 第一批设计预览（普通攻击 / 强击）

仅表现层：命中回执、伤害骰、规则、AP 全部不动。数值与公式见参考实现 `scripts/battle-hitfeel/hitfeel.py`
（后续 Swift 版是它的逐式移植），预览由 `scripts/review-hit-feel-v1.py` 合成：与现有离线战斗复核同一场景、同一英雄姿势时钟、
同一怪物原画和落地碎光，左为“现在”（按当前 Swift 公式复刻），右为“新”。**离线合成，光影近似，不是 UIKit 或实机录屏。**

## 新增/改动
- **命中停顿**：接触瞬间怪物和镜头一起定住 0.10 s（与英雄现有 0.10 s 接触姿势保持一致），定住期间闪光、火花、伤害数字已出现；
  释放后才开始后仰、震动、尘土。现在是英雄停 0.10 s、怪物却立刻后仰，两边不同步。
- **分档**：伤害 ≤5 轻、6–11 中、≥12 重（致死至少中档）。档位决定闪光大小（34/46/64）、火花数（14/22/34）、镜头力度（0.7/1.0/1.45）、叶片数、震动强度。
- **镜头**：停顿时轻微推近（3.2% × 档位）；释放后沿攻击方向猛推一下再弹回（6 单位 × 档位，阻尼两次来回），带 0.35° 的小旋转；HUD 不动，沿用“减弱动态效果”时关闭。
- **怪物反应**：受击瞬间轻微压扁（停顿期保持），释放后先快后慢的后仰（略过冲再回位，约 0.5 s 回稳），压扁/拉长按档位。
- **命中闪光**：原来是一大团金色光晕持续约 0.5 s，盖住怪物；改为：怪物命中遮罩 0.04 s 全亮、0.12 s 内消退 + 极淡全身提亮；
  接触闪光（十字尖星 + 亮核）只亮 0.06 s；一圈冲击波 0.26 s 扩散消失；沿攻击方向喷出的火花条（带阻力、部分受重力，白→金→橙）；脚下尘土在释放时扬起。
- **鹿灵叶片**：被打时飞出 3/6/10 片叶子（绿色，不发光），飘落并旋转。其余怪物之后各配自己的碎屑。
- **伤害数字**：弹出放大（1.7×→1.0× 用时 0.09 s）、沿缓出曲线上浮、0.55 s 后淡出；重档数字更大、金色。
- **手机震动反馈**：命中瞬间触发 UIImpactFeedbackGenerator，轻/中/重对应 light 0.7 / medium 0.85 / heavy 1.0；被怪物击中（未格挡）与击杀时同样触发（击杀额外一次延后 0.12 s 的 rigid）。
- 保留不变：挥击弧与剑光、落地反弹碎光、伤害数值/回执、死亡右吹。大光晕 sprite 与 26 颗光点移除，地面与命中处的泛光减半。
