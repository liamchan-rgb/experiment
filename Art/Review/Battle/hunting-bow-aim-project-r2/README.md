# 猎弓第一关键帧 r2 · 接合和遮挡返修

用户指出 r1 肩部连接点错误、背心外露、拉弦侧袖子被向后拉扯、持弓臂错误覆盖在躯干上，本轮针对这些问题修改原生分层候选。

[整身 3 倍图](first-frame-3x.png) · [原尺寸](first-frame-native.png) · [独立原生资源及配置](../../../Parts/P1-Battle/hunting-bow-aim-project-r2/README.md)。近侧上臂与前臂拆层，持弓侧肩根藏入外套后；补齐外套、清理头部裁片夹带的背心，重接拉弦袖口。脸/发（颈部以上）与腿部/靴子区域逐字节比较保持一致。

根线程亲看整身效果；仅一张第一关键帧待用户审核。没有图像生成，没有新动画或 IPA，没有运行 App/模拟器/实机，没有委派智能体。
