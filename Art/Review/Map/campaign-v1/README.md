# M3 正式行程 · 三倍移动 · Build76

[正常行走 GIF](travel-normal.gif) · [致死命中与胜利收尾 GIF](encounter-normal.gif) · [完整遭遇 MP4](encounter-full.mp4) · [实施说明](../../../../docs/planning/random-map-v1/build76-campaign.md)

本轮沿用已经认可的 v3 不规则路网/建筑前场与原人物、服装、武器挂载资源，接入同一规则引擎的正式探索、战斗、奖励和独立行程存档。正式队伍暂为 P1 魔剑士 / P2 游侠，两人同行使用较慢者速度75；原演示三人各为75/114/135，均为此前的三倍。动作仍按行进距离推进，起停原帧及战斗出招速度保持。地图门前才结算每条边，首个敌人节点中断路径。地图与战斗共用 GameEngine，战斗中的实际伤害/物资/装备/奖励可续档，不在返回时重置。

这些文件是实际 Swift 会话/生产布局/道路/步态/战斗姿态、接触时机、光照字段与现有 PNG 离线合成，光照、UI、阴影及地面材质近似。不是 UIKit/Metal 截图、模拟器或实机录屏。正常速度：地图370×20ms=7.40秒；完整战斗948×20ms=18.96秒；胜利 GIF 取战斗帧650–947，298×20ms=5.96秒，明确为尾段。50Hz是预览取样/GIF时基，不代表实机帧率测试。

主线程独自检查完整地图、关键全帧及14页接触表，涵盖370个行走、948个战斗源帧的小图；检查转码后首/中/末帧的完整画面，并修复 GIF 从中间差分帧切片导致的状态栏残影。短 GIF 从完整画布重新编码，再做无损优化，不使用有损 speckle 压缩。头顶怪物血条随死亡消失，下方状态仅显示玩家；胜利文字无第0轮。审核不是1318帧逐像素全分辨率验收，实机仍由用户测试。新美术用户认可为 null。

普通鹿灵/鹿王沿用既有鹿美术，分别完整复制原 wolf / caveTroll 数值、AI与掉落（本地模板ID/名称单独区分），不声称六种规则怪物外观已经完成。191项纯 Swift 测试、原道路/战斗/特效/模组四组回归及 iOS 设备 Release 归档通过。原地图/步态和规则目录未改。

复现：`bash scripts/check-campaign.sh` 导出真实会话与回执，再用 `python scripts/review-campaign.py` 合成。需 Swift、Pillow、NumPy、中文 Noto 字体、ffmpeg 与 gifsicle（或设置 GIFSICLE）。不启动 App。data 中9个 JSON 经干净目录重导出，忽略每次新建会话的 UUID 与 revealed/acted 集合编码顺序后结构一致；其中行走帧、战斗帧、地图、道路与回执摘要未经归一化即一致。中途暂停精确恢复、每边结算、真实战斗命中及胜利后完整存档一致性由 CLI 断言和测试覆盖。

后两项：M4 单节点内容编辑；随后是行程行囊/换装与队伍配置。
