# 不规则路网与建筑节点 · Build75

[正常行走动图](walk-normal.gif) · [10节点整图](map-10-overview.png) · [30节点整图](map-30-overview.png) · [4/10/30×三种子对照](sizes-seeds.png)

本轮修复两个问题：方格邻接导致形制方正；建筑和独立道路圆点分离。生成器v3使用非对称散点/物理间距松弛、Delaunay候选边、带距离权重的连通树和精确环路。路径绕开建筑，并在折角处圆滑；非邻接路段保持净空，不出现未对应真实节点的视觉交叉。版本2资料保留。

建筑本身就是地点：道路端点位于其门前，建筑x与端点相同、脚底在北侧26单位，点建筑或徽记到达同一门前。徽记在真实PNG轮廓顶部14单位处，考虑营帐的真实宽高比和各图透明留边，不再悬在旁边草地。缩略图使用真实比例建筑。人物/装备/步态/原图与规则不重制，旧静态地图仍用原平滑流程；生成道路直接使用校验过的圆滑采样，避免再平滑后穿建筑。

182纯Swift测试、648组规模/种子、24组单类配额与0/最大环路案例、36组道路方向退化检查通过。78组正式适配/巡逻/清障/无假交叉检查新增门前对齐、徽记在屋顶上方、道路不进入建筑显示体（含边距）。九个导出布局的132个徽记与实际PNG Alpha边界逐一核对，均相距14单位。原13规则/目录源文件摘要保持；新增/旧人物、建筑PNG均不修改。

主线程亲看4/10/30完整图、三种子对照、关键全帧和正常GIF实际解码400帧的10页接触表（每格240×135），没有声称400帧逐像素全分辨率审核。GIF400×20ms=8秒，来自生产Swift路径、徽记和动作采样/实际PNG，阴影/材质/光照与UI离线近似，不是App、UIKit、Metal或设备录屏，不测设备FPS。安装/实机操作交用户，美术认可null。设备归档/包检/直接IPA见Media/Build75。
