入口仍是原地图左下“随机地图”。总数4—30，起点1；总数/战斗/Boss/奖励/空地/额外环路均可输入或拖动整数滑块，两者同步。改总数按建议自动分配；改单类保留当前值，优先用空地补差，再调整其他分类；每次结果满足各分类加起点等于总数。种子仍数字输入和随机换种。编辑后旧生成结果立即失效。

每节点绑定一栋建筑：起点蓝营帐，战斗红色木寨，首领紫晶石门，奖励绿色补给棚，空地水井与路标。点击建筑前往关联的实际道路节点；本轮仍是林地预览，无正式怪物/战斗/奖励结算和战役存档。新建筑为主线程使用图像生成工具创作、二次修整并技术性修复透明边缘，原图/导入方式/摘要保存在Art/Parts/Map/meadow-locations-v1，用户美术认可null。

建筑先分配保留地块，并检查道路、驻足点、标记与建筑显示矩形；密集图高度随行数扩大，地面Mask、SpriteKit雾层、Metal接收网格/道路UV/阴影范围、相机及缩略图使用同一高度。生成器版本2；版本1审核资料保留，不承诺同一种子跨版本图形一致。

181项纯Swift包测试通过；648张4—30规模/24种子地图的精确配额/图连通/道路端点/每节点一建筑/道路净空检查；24组4/10/30规模、四类单一配额、0和最大环路压力案例；78组生产适配/平滑曲线/巡逻/交叉检查，9张实际Swift地图与400个20ms动作采样导出。原13个上游规则/目录文件摘要未变。测试/导出日志见本目录，设备编译和IPA校验另见Media/Build74。

画面为生产Swift生成与实际项目PNG离线合成；道路着色、阴影和光照近似，不是UIKit/Metal/设备画面，不验证帧率。主线程查看建筑透明原图、运行宽度、三张全图和关键全帧，并查看最终GIF400解码帧的10页接触表（每格240×135）。不声称400帧都做全分辨率像素验收，未运行App/模拟器/实机，安装操作交用户。
