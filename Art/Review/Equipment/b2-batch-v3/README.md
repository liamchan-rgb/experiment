## 原因及修正

r2把大导板按统一比例缩小，再将肩袖、前臂、胸甲和护裙分别挂到猜测的点；源袖长与目标骨长不一致，侧面缺腕标记时还用了肩肘方向代替前臂。斜向直接压窄正面胸甲，袖子仍按正面，所以只挪位置不能解决。

新独立衣物源有正前、斜前、正侧、斜后、正背五种真实视角。皮甲背部去掉前胸搭扣，斜前胸缝与腰扣按透视偏向前方，远肩袖缩进。源衣片在制作时按命名颈/肩/肘/腕/腰控制点一次裁制到原256静止人体；不按alpha外接框自动居中，不每帧缩放，不改身体来迎合衣服。

胸腰到护裙根部共用同一表面，腰以下才逐渐跟随对应腿。整条袖子共用肩肘腕变形，肘部按连续角度过渡，避免直接混合两个旋转造成反折。肩甲留在肩口，内衬随上臂与前臂；后侧袖降低亮度；侧向远袖的活动内衬按原body.arm语义区域加一像素衣料余量限定可见范围，保留原后臂，去掉伸出手臂的白色薄楔。肩甲本身不受此内衬可见区裁切，不复用旧衣物alpha。侧向原动作没有正式腕点时，从原手层靠近肘的五个实心像素建立固定袖口标记；这是读取冻结身体制作标记，不是用新衣alpha猜挂点。

战斗仍用原六动作，按战斗自身的(117,141)肩/(128,158)肘/(145.6,163.7)腕裁制，不能直接照搬行走姿态。肩甲和腰带随躯干，近袖分上臂/前臂并有隐藏搭接，髋片随各大腿，原裤子保留。采样使用n/count，避免把末帧提前当作duration边界。
