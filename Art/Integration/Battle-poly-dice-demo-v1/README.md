# build48 多面骰接入

本轮替换共享MeadowBattleDiceView，纯Foundation的PolyhedralDice为UIKit与离线审核提供同一套顶点/面法线/面数字/旋转/透视。三角形D4/D8/D20、方形D6、五边形D12、鸢形D10；遮挡与面光照随三轴转动。原回执到达后连续减速0.65秒落到真实结果面，随后淡出。普通攻击预览读实际武器公式，技能按count逐颗显示；固定加值单独标记，原核心/目录/随机/AP规则不改。

多人仍复用单人布局/地图/进度条/状态条，骰子随完整人物根节点前冲并按组宽平滑内收，避开敌血条。单人沿用原定值结算，使用同一显示组件。旧强击/护盾/恢复/粒子/死亡时序和怪物动作保持。

D4/D10离线测试装备不进入默认目录；突袭/符文斩只用于既有公式审核，不算B2/B3演出或装备界面完成。当前活动技能最多三通道，未来复杂技能头顶拥挤需单独集成审核。
