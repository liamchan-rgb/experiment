# 战斗光效接入demo · build40

将用户认可的v3展示范围接入现有战斗：保留强击5点伤害/AP规则，输入只预留AP，实际接触由生产MeadowBattleImpactClock一次性驱动HP/护盾/治疗、伤害数字与死亡。强击包含400ms起势、648ms到接触及80ms命中停顿。攻击/怪物冲撞均不在点按钮时提前扣血；HP0在同一回调立即启动右向风化，不等待回位/胜利动作。非致死不消散。关闭/重试取消旧回调并重置消散与照明。

技能卡支持鼠标悬浮、键盘焦点和触屏按住的预示，普通0.28/强击0.90固定光效，无蓄力机制。强击预示压暗34%，确认后连续衔接56%暗场。脚下预示环在400ms起势结束、开始出招前消失，位移/命中/回位不留圈。默认强击名称/数值保持，不把样片18点伤害加入游戏。

导入脚本 `scripts/import-battle-effects-demo.py` 复用v3生成器的固定UV碎片、粒子规则和v1光学素材，导入四个光学PNG、局部命中mask及48帧body/wind图集；body384×256、wind640×320、偏移(0,-32)，8列/40ms，首帧采用v3首次可见采样32ms。运行时只按时钟裁片，不每帧重新抠图。阴影使用剩余body轮廓，粒子不投完整怪物影子。原动画数据备份source/pre-vfx-animation.json，运行数据只替换已展示v3攻击曲线；行走与人物外观不改。

UIKit合成包含背景/前景压暗、角色轮廓层、地面暖光、刀光/命中爆光与粒子层。离线动图是共享素材/坐标/时间数据的Pillow审核，不能声称GPU逐像素一致或实际输入运行；实机由用户安装IPA验证。纯Swift检查覆盖旧战斗、延迟命中门控/HP0同步/非致死/重复输入/取消重试/护盾及15/30/60/120Hz，另保留道路/行走/姿态检查；只设备Release归档，不运行模拟器或App。
