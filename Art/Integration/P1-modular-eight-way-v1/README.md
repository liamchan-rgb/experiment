## 固定注册与相位

每方向仅用一个整数父平移，将站姿 neck 对齐128,132，同一偏移用于该方向所有姿势/部件/关节/足底/挂点；不逐帧抹掉头部起伏，不按内容边界缩放或对齐。旧 hip 的定义存在差别（166与176），不拿这些不同定义的点做身高修正。完整映射见 authoring.json 和 mapping.json。

全局phase0..3为身体右脚支撑，4..7为左脚；仅旋转既有八帧循环起点，不重排中间动作、不丢帧、不重复。正下源序8,1,2,3,4,5,6,7；左下/左/左上/上源序5,6,7,8,1,2,3,4；其余保持1..8。原复合支撑标签保留在 sourceSupportLabel。

指定起停仍接原生walk01/08，entryPhase/exitPhase按方向记录。不能将每个方向的指定起步强接全局phase0。任意相位停车、统一完整骨架重标定和新模组demo接入未在此轮完成。

## 主线程发现并修正

- 正下衣物包中的裤靴拆入共用 lower；两衣型52个裤靴层逐字节相同。
- 蓝色长外套在四斜向和背向原为短衣摆。保留原躯干/袖子与四肢，工具绘制13姿势柔软分衩长摆；固定全图1254→1024后提取，保留金边，独立hem.front覆盖原短下摆。左右反射同时保留目标方向的既有蓝色材质盘。第一次工具稿把剑画进衣服，已保留并另修无武器稿后再提取，不能把含剑下摆交付为空背衣服。

源文件摘要见 source/consumed-inputs.json，工具原稿和提示词均保留。新衣摆只导入服装，工具重画的脸、手、腿均不导入。原八向部件/模板、旧demo及所有历史候选保持。
