# B2两甲 r4：正下肩部和八向护肩随动

用户反馈r3：“正下方向，感觉是在扭肩膀，其余方向的手在动，但是护肩却保持禁止”。此处“禁止”按上下文理解为“静止”。原反馈记录在../b2-batch-v3/user-feedback-shoulders.json。两件护甲需要修改，不得把r3视为用户通过；原先通过的重剑、传奇权杖、力量徽章和行动戒指保留其精确认可范围。

## 修改

正下方向原版将左右肩标记的高度差映射成整件胸甲的旋转，因此正常交替摆臂会带动胸甲左右拧。r4用原颈部与骨盆共同驱动正面胸甲起伏，两侧护肩再各自跟随对应手臂做幅度受限的旋转和平移；肩甲和袖面保留搭接。斜向、侧向与背向护肩也跟随各自手臂适度摆动，后侧继续保持阴影与原有身体轮廓约束。角色原身体、头、手脚、步态、层序、衣物源和四件用户已通过素材保持。

六个战斗动作的素材审核预览中，也将近侧护肩从固定躯干中拆出，让它围绕原肩点跟随手臂小幅转动。此为离线审核额外层，现有demo和生产动画代码未接入该层；不把预览说成游戏运行结果。

## 自查

由root独立完成返修和审核。整身对照两甲八向全部128个行走姿态；另看八向站姿、起步/收步及与指定行走入口/出口的衔接80个姿态，正下和正左聚焦GIF全部解码帧，两个攻击GIF共120帧以及其他五战斗动作各五个关键位置共50帧。八向原尺寸与两倍整身联系页和前后对照保存在contact-sheets/，不是只放大局部看肩。逐帧图像检查不等同实机或连续视觉播放验收。

geometry.json：两甲所有姿势的肩甲与袖面接触检查未发现断开；正下胸甲不再跟随左右肩高度差额外旋转；八向两侧护肩的相对运动数值与raster统计在文件中。检查作为辅助，不自动代表美术合格。16套原部件组合共1664次合成、两甲共208个显式姿势绑定通过；全部16个方向/装备站姿部件像素不变，非正下胸腰部件像素不变，原身体/动作/旧r3/四件认可资源受保护。832个可编辑SVG的嵌入图层已和最终透明PNG逐字节同步。检查/重导记录见verification.json、combination-verification.json、reproducibility.json、change-scope.json、editable-verification.json。

正常行走GIF为八帧、每帧120ms；正下与正左另有两甲并排整身GIF。正下和正左另提供22个阶段的起步、两圈行走、收步GIF，首尾站姿480ms、动作每帧120ms。审核页支持八方向、两组人物、起收和六个战斗预览，手机/平板/桌面浏览器检查见browser-qa/。用户反馈存在浏览器本地，导出JSON后发回聊天，网页不会自动写入GitHub。
