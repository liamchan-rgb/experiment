# 新分层八向资源接入 demo

用户2026-10-25“开始下一项工作”授权集成，未因此扩大新美术认可。`selection.json`选用上一轮同一baseID的两套预设，通用装配器离线烘焙到普通图集；App按数据列出“P1 衣装”选项，当前不是任意部件的运行时自由混搭界面。

每方向13格：idle00、规范相位walk01..08、原生start01/02、stop01/02。每格256，四行分别为下/左/上/右和右下/左下/左上/右上；同一208张装配在导入后逐格RGBA摘要保持，没有裁边适配、缩放、重绘或换身体。`source/`保留旧P1运行图集/足点JSON，其他历史素材不改。

P1沿用24个距离刻度，每3刻度取一张步行图；运行帧25/26/27/28对应源列9/10/11/12。前景切片、Metal阴影UV、足点都使用同一映射；阴影外观随帧快照一起传递，切衣装不重置路线、朝向或相位，也不在每帧重新上传图集。P2/P3保持原24姿势/25列及足点数据。

控制器用原方向entryPhase/exitPhase：先两帧起步，随后原生walk01；结束循环到原生walk08，再两帧收步。起步时暂缓P1路线移动，其他角色不受门控影响。收到停步请求时先在原位置播放到指定出口，最多补当前循环余段，再收脚；恢复请求可取消尚未进入收步的排队。此实现**不是**新增任意相位的收步美术或精确刹停，后续可单独增加更短的制动过渡。

方向选择继续使用原五度防抖和投影距离度量，移动中转向不清距离相位。只给距离转刻度加1e-9数值容差，避免斜向浮点运算恰好落在边界下方造成重复采样；没有扩展成像素插值或新的中间帧。

新足点直接来自统一motion的2D soleMarkers，不凭旧图的腿摆幅编造新3D lift。实际显示/阴影/投影接地仍需用户设备检查，未把离线资料叫作实机画面。

重导：`python scripts/import-modular-p1-demo.py`。复核：`bash scripts/check-modular-locomotion.sh`（纯Swift，无模拟器）生成trace后，`python scripts/review-modular-p1-demo.py`从实际图集抽样生成正常GIF。macOS检查与设备归档来源、主线程逐帧范围和交付回执见 `Art/Review/P1/modular-demo-v1/` 与 `Media/Build39/package.json`。
