# P1 头部拆分 v1（五官/性别自定义 第 1 步）

`scripts/build-p1-head-split.py` 用原分层合成器把 60 张 P1 地图图集重新渲染，并按图层拆成：

- `P1SplitUnder<状态><Directions|Diagonals>`：画在后发之前的层（正下/左/右视角的背后武器）。
- `P1SplitBody<状态><…>`：其余全部（身体、衣服、护甲、武器、头部皮肤、双手），不含五官和头发。
- `P1Head<部位><款式><…>`：每个头部部件一张页，已按每帧头部位置放好。
- `P1HeadSplitManifest.dataset`：状态、部件、各衣装默认头、叠放顺序。

状态 20 个：绿衣/蓝衣 × 5 种武器状态，加皮甲/符文甲 × 5（穿甲时两套外观的身体完全相同，已校验后合并）。

`verification.json` 实测：

- 3,120 个格子，手从不压到头部（运行时可把头叠在手上而不改变像素）。
- 每个头部部件与装备无关（各装备状态下逐像素相同）。
- 用原头重叠拆分结果，与原 60 张图集最大相差 1 个色阶，共 997 个像素（软边预合并的 8 位取整）。

运行时由 `Sources/Game/P1AppearanceCompositor.swift` 按 `under → 后发 → body → 眼 → 眉 → 鼻 → 嘴 → 前发` 用 CoreGraphics 叠成与原图集同格式的两张图；
`Tests/P1AppearanceCompositorTests.swift` 在模拟器上对全部 60 张图集逐像素比较（容差 2 个色阶）。
原图集、名称、尺寸、锚点均不改动；本步尚未接入游戏画面（默认仍直接使用原图集），不改变任何现有显示。
