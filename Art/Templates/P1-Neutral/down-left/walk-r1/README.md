# 左下中性动作模组 r1 · 待用户审核

固定256×256、p1-chibi-v1。左下为三分之四正面，近侧为角色左侧（屏幕右），远侧为角色右侧（屏幕左）。新绘中性源稿固定0.17等比缩放及(24,26)登记；不是翻转左上或修改旧整张步态。头部无五官/发型，供后续独立挂载。

13姿势：00站姿，01–08行走，09–10起步，11–12收步。clip内frame与存储序号不同：起/收步分别用1/2。正常行走8×120ms；指定路径为idle00→start01/02→walk01–08循环→stop01/02→idle00，不代表任意步相中断。

8语义层分别输出头、躯干、左右臂/手/腿；source中背心、短裤、双完整臂/手/腿独立。肩口、腰和裤口共用空间变形域；两个裤口分别跟随对应大腿，双手与各自手臂使用同一采样域。膝部依据本正面斜向原姿态投影，摆动足带轻微屈膝；不套侧向屈膝角度。保持原地脚底和近远层级，头有轻微步态随动。

重现（仓库根目录）：

python scripts/reexport-down-left-motion.py
