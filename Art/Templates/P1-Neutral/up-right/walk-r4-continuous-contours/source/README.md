# 源区域归属

原始生成图完整保留；固定注册将其放入共同256像素画布。alpha以128为界统一为透明/不透明；这不是按肤色删除像素。后续肢体和衣物使用显式空间边界，所有肤色/轮廓色均保留。

`torso.png` 含中性安全背心/短裤及完整颈部；`arm.*.png` 含整侧手臂与手，`hand.*.png` 是其中手部的子区域；输出时在同一网格上分配为互补层。`leg.*.png` 含整腿完整轮廓及裤内髋根覆盖。源轮廓边界、延入区域和固定脚源注册写在作者脚本/清单中。运行时不拟合图片边界、不按外观选择人体。

来源使用imagegen完成整身源绘制；主线程负责选择、否决、分层、动作修复和审核。所有数据生成/掩膜/装配脚本只做离线注册和技术合成。当前未制作新头发、面部、换装组合或起停动作。
