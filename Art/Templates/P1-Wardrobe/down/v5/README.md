# 向下正手垂剑 · v5 单帧回审

v4 把共享拳头单独转向，虽然方向对了，腕口和前臂却接得生硬。v5 改成从原袖口连续延伸前臂、手腕和握剑的手，不再单独旋转拳头。现在的站姿是手臂自然下垂，剑尖朝下略偏外；刃面收窄，护手短并与剑身在同一平面透视内。我认为这一帧的持握动作现在成立，仍等用户审核。

[00站姿与手部放大](review.png) · [完整站姿PNG](00.png) · [注册及像素范围验证](validation.json)

输入底图是 v4 的无手剑装配图。图像生成工具输出了整张角色图，且改动了其他区域；本稿只按固定注册裁取并叠加左下持剑区域，底图其余像素保持不变。重建方式见 `python3 scripts/preview-point-down-grip-v5.py`，原图与实际提示词见 `source/`，变换和裁切位置见 `registration.json`。

这是单帧动作研究，不是已验收的换装生产件：前臂、手和剑目前在同一张叠加图内，尚未拆成可独立换装部件，也没有扩展到九姿势、生成动画或生产清单。用户认可仍为空。
