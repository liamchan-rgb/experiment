v2 的持剑构图恢复为自然下垂、剑尖朝下的姿势。用户指出 v3 抬起剑尖、手型不自然，本稿只回审00站姿，不扩展步行动画。

手臂顺势下垂。共同闭拳绕握点转90度，使拇指落在下方护手一侧；食指和其余卷曲手指在剑柄前景，柄尾位于腕侧，刃从手指／护手一端向下。剑尖向外偏左。手与剑仍分开存储，手柄／指节重叠并由手指遮挡。

独立短剑采用固定1254→96整画布最近邻导出，手柄中心按显式pivot放置；没有按alpha外接框自动适配。刃宽控制在约3–4个局部像素，显示亮刃与窄暗侧面；护手按近端稍大、远端缩短的斜向透视收窄。原头部、衣物和其余身体像素保持原样。
