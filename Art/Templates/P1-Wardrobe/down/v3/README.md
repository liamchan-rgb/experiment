# 向下正手持剑 · v3 已要求继续修改

本版未获认可。用户指出 v2 仍像反手握柄、剑宽面正对镜头，又指出第一张修改稿的护手没有随剑身转动。之后检查发现 v3 把剑尖抬向左上、手型也不自然，因此被要求继续修改。该 [00 站姿与局部放大](review.png) 仅作历史稿，当前回审见 [v4](../v4/README.md)。

本版曾尝试将拇指／食指靠护手、让出刃端向上偏外，并缩短护手两翼。该方案改变了原来的垂剑姿态，用户未认可；这些内容不构成当前持握标准。

手和剑仍是[两个独立透明部件](independent-parts.png)，没有将剑柄烘焙进手，或将皮肤画进武器。整画布采用明确固定导出：手为1254→64，剑为1254→96，按 registration.json 的明确区域及各部件实际握心 pivot 导出，统一挂到原 (102,170)；不按 alpha 外接框自动适配。源稿未精确遵守提示中的尺寸和握点，因此显式记录离线尺寸及实际柄心校准，不把本稿当作标准坐标已完成验收。头部、衣物和其他身体像素保持原样。

复现：在仓库根目录执行 `python3 scripts/preview-forward-grip.py`。该脚本只是单姿势美术预览，调用原通用定位函数，不修改通用装配器、动作文件或已认可资源。新手型尚未写入九帧公共底模，新剑尚无生产清单；本轮也没有新动画、24种新组合或完整生产准入结论。后续仍以共同持握动作类型复用，不按具体剑 ID 配套身体。

源稿、实际提示词和参照摘要见 generation.json。最早联合概念稿未满足整人坐标注册，仅作设计参考；第一张向下出刃及宽护手稿保留在 drafts/downward-study。当前美术认可为空。
