# 战斗美术要求

## 怪物的体量、比例与压迫感

用户于2026-10-25要求：**“之后怪物的美术要有压迫感，参考八方旅人比主角大，比例更真实。”** 此项是后续怪物原画、分层、动作、场景装配与审核的共同要求。

- **体量关系**：怪物与主角同屏时，应明确比主角更大，主体的躯干、肩背、四肢和占地共同体现体量；角、尾巴或光效的外接范围不能代替主体大小。
- **更真实的身体比例**：依据物种组织头、颈、胸腹、骨盆及四肢，关节朝向、肢体粗细与承重关系要可信。保留像素画风，避免把怪物沿用成主角式大头短肢的可爱比例；幻想结构也应有清晰的运动与支撑逻辑。
- **压迫感**：通过有重量的体块、清晰有威胁的轮廓、警戒/攻击姿态和有力度的动作表现。扩大图像、提高亮度或增加特效不能代替这些设计。
- **同场比较**：在实际战场构图、相同透视和地面尺度下，与主角并排检查站姿、攻击、受击和退场；查看整场以及1×/2×整身，兼顾足底、阴影、接触位置、动作范围和界面遮挡。不得通过缩小主角、错置远近或透明画布尺寸伪造比例。
- **尺寸确定**：用户没有指定统一的高度或宽度倍数。按具体物种、主体体量和战场可读性确定，留存与主角的同场对照；不自行把某个倍数写成已确认标准。

这些要求从本次记录起约束后续制作。本次仅记录要求，不重画或调整已有怪物，不将现有鹿灵/光效候选自动标记为符合标准或已获用户认可。修改美术时仍由主线程负责修复与最终审核，并按AGENTS.md交付正常整场GIF、已验证HTTPS直链和站姿。

当前build40集成见 [demo接入说明](../../Integration/Battle-effects-demo-v1/README.md)，设备测试仍由用户反馈；此前已展示的离线v3及原范围见 [effects-v3说明](effects-v3/README.md)；[v2](effects-v2/README.md)与[v1](effects-v1/README.md)保留为历史。怪物HP归零时，伤害数字与向屏幕右方吹散的粒子由同一命中事件同时触发，不等待攻击收尾，非致死不消散。脚下提示光圈在施放开始时消失，强技能悬浮发光时同步压暗战场，确认后连续衔接释放压暗。技能没有蓄力层级，悬浮提示按技能固有强度显示。
