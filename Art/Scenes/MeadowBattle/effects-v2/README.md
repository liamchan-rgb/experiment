# 战斗光效v2 · 光圈退场与强技能压暗

用户反馈v1人物已出招离开原位，地面光圈仍留在起点；同时要求更强技能发光时压暗画面。本版只修正这两项演出时序与光照，仍为离线候选，尚未接入UIKit悬浮/触摸/键盘或实际技能规则；artApproval=null。

光圈只用于选择与出招前的提示，确认后2.84–3.00秒淡出，3.00秒出招开始即完全消失，冲刺、命中、回位及死亡阶段不再绘制。不会把旧光圈留在原点或改成跟随人物移动的光圈。

普通技能提示不压暗；强技能从1.60秒获得焦点时，光点、地面微光和选择框光晕与背景压暗同步进入，280ms过渡后固定降低34%战场背景亮度。施放者与界面保持可读，目标适度压暗。2.60秒确认时连续衔接至释放阶段的56%压暗，不先恢复再压暗。退出焦点的交互尚未接入；本样片表现切到强技能并确认的路径，不宣称所有输入路径已验证。技能强度固定为普通0.28/强0.90，280ms仅为光效入场过渡，悬浮停留不会蓄力或升级。

复用 [v1素材](../effects-v1/README.md) 的全部光学PNG、源稿、攻击曲线及既有场景/人物/怪物。v1动图、脚本与审核记录原样保留，新时序数据见effect.json；`scripts/review-battle-effects-v2.py` 单独输出 `Art/Review/Battle/effects-v2/`。没有重画或更改怪物体量，后续怪物要求仍见 [战斗美术要求](../README.md)。

正常演出仍为180帧×40ms=7.2秒；最终GIF解码联系页、原尺寸关键帧、整身1×/2×攻击姿势及主线程审核记录随版本交付。需要实际发正常整场GIF、已验证浏览器HTTPS直链及站姿，不能仅给脚本或数值检查。没有App/GPU/模拟器/实机执行或IPA。
