# 战斗光效v3 · 致死命中同步向右吹散

用户要求怪物死亡改成粒子被向右吹散；一旦HP清空就立即触发，并与伤害数字同时出现。本轮新增v3离线候选，保留v1/v2全部素材、动图、脚本与审核；不是App/GPU/设备画面，尚未接入真实战斗事件，artApproval=null。

## 触发与表现

样片用单个命中事件（3.648秒，HP18、伤害18）同时计算剩余HP、数字显示与死亡状态。只有HP降到0才启动碎解，不再等待4.28秒攻击收尾。40ms采样的首个命中帧是第92帧/3.680秒：HP0、伤害数字、首次轮廓缺失、死亡状态及第一批粒子均在这一帧出现；3.640秒前一帧仍未命中。该32ms为采样边界，五项信号没有互相错后一帧。非致死5点伤害的状态采样不启动死亡。

碎解前沿由左向右推进，保留细小不规则边缘。650个确定性粒子从既有怪物UV切片发出，带暖金照明和少量复用光点的细长拖尾。水平方向速度均为正并向右加速，垂直仅轻微飘动；边缘前淡出，避免右边界硬裁切。怪物实体在命中后760ms内消失，空中粒子继续向右飘散并熄灭。地面影子从剩余实体alpha生成，同步退场，飞起的粒子不保留完整怪物影子。

沿用v2：光圈3.00秒施放起不再绘制；强技能悬浮发光与34%背景压暗同步，确认后连续衔接56%释放暗场；技能固定功率，无蓄力等级。人物攻击曲线、既有角色/怪物/场景PNG及光学素材保持，来源见 [v1](../effects-v1/README.md)；上一轮时序见 [v2](../effects-v2/README.md)。本次不调整怪物体量，长期要求见 [战斗美术要求](../README.md)。

## 生成与检查

`python scripts/review-battle-effects-v3.py` 输出180帧×40ms/7.2秒的正常整场GIF及其实际解码联系页、站姿、命中图与人物整身1×/2×姿势页。`event-check.json`记录同步帧与方向、光圈/压暗保持；`preservation-check.json`记录229个旧文件远端字节保持；主线程范围见art-review.md。数值检查不是美术认可，静帧查看不称连续播放。动图与已验证浏览器直链、站姿须实际交付。

没有修改App的5点固定伤害、HP逻辑或技能菜单，没有触摸/指针/键盘接入、模拟器/实机执行或IPA。样片的HP与18点伤害仅供检查这条致死演出；人物自身死亡、其他技能、音效及性能仍未验收。
