# 战斗光效演出候选 v1

用户2026-10-25要求先做一版效果，明确没有蓄力层级；更强技能在指针悬浮到选择框时应有更强光效。本轮为离线整场演出与选择框概念样片，尚未接入UIKit指针、触摸、键盘焦点、真实伤害或实际技能菜单，不是App录像或实机运行结果。新美术认可为null，不制作IPA。

## 固定技能强度与选择反馈

`effect.json`的两个技能是样片预设：普通斩击0.28、裂光斩0.90为视觉强度，非伤害数值或蓄力等级。悬浮仅提示；保持悬浮不会提高强度，不消耗行动点、不扣血；确认以后才进入完整演出。样片先普通再强技能，当前只播放一次强技能。后续接入时鼠标悬浮、键盘焦点与触屏选中均应能看到同一提示，离开/取消需还原，不应让强光遮住文字或禁用状态。

## 演出与素材

整段7.2秒、180帧×40ms，正常时序：普通悬浮0.6–1.6s、强技能悬浮1.6–2.6s、确认2.6s、出招3.0s、实际刀尖接触3.648s、命中停顿80ms、4.28–5.40s怪物解体、粒子随后消退并恢复环境。暗场最高降低56%背景亮度，界面与施放者保持清晰；同一接触点驱动白金核心、局部轮廓泛白、散射火花和地面暖光。无全屏白闪。普通与强技能的悬浮幅度分别恒定，周期性光点运动不是蓄力。

保留原战斗人物/场景/怪物PNG与原动作数据。`attack-clip.json`是复制的原攻击曲线，只调整0.45/0.54/0.62三个关键点的肩肘腕，使刀尖实际接触前腿轮廓内；手剑仍共享同一变换，旧版动作不覆盖。初稿命中点过低且整只怪物泛白，保留reference/first-pass-low-contact.png，当前改为实际刀尖坐标与局部亮斑。没有以新增走路资源冒充战斗换装已接入。

光学素材由image_gen生成，原1254×1254透明图及原提示词保留source；工具没有严格按请求输出1024尺寸，切片使用实际尺寸的四等分网格，见effect.json。四格内部只作透明边裁剪、缩放和合成，不重画人物。`slash.png`、`burst.png`、`ring.png`、`mote.png`分别为刀弧、命中爆光、脚下提示环和粒子。粒子解体使用同一固定阈值场；光点出生时间与对应区域消失一致，阴影由剩余轮廓同步投影，死亡末帧怪物及其阴影完全消失。

## 生成及后续

在仓库根目录运行 `python scripts/review-battle-effects-v1.py`。读取旧渲染模块时只加载定义，避免执行其文件写入循环。现有分层与动作采样复用；Pillow仅进行切片、原像素变换、光照/消散mask和合成。输出见 `Art/Review/Battle/effects-v1/`，最终GIF解码后生成联系页，不能把数值检查称作主线程美术认可或连续播放验收。

后续待确认：本次强弱提示与光效观感、转成可交互选择的方式、技能固定强度配置、人物死亡对应样片、实际战斗服装兼容与运行性能。可复活倒地和真正消散的规则未在本轮引入。样片中的18仅表示一次致死伤害演出，不修改现有5点固定伤害规则。
