## 固定挂载约定

- 四张 PNG 均为 **1309×1201**，左上原点，保留整画布；原生成图片逐字节另存，不重新裁边、改色或过滤透明噪点。
- 全部使用同一个等比缩放和同一个偏移：`s=min(容器宽/1309, 容器高/1201)`，整张画布居中。禁止按各自透明外框再居中、单独拉伸或错开地面。需要铺满其他宽高比时，应另审裁切范围。
- 插入层顺序为：远景0 → 地面10 → 中景20 → **独立角色接地／投影30 → 独立角色35** → 前景40。
- 按已认可图中实际鞋底／底边预留：人物足底约 `(0.30,0.69)`，朝右；史莱姆底边约 `(0.76,0.685)`，朝左。坐标相对于完整画布。不是运行时根据 alpha 包围框反推挂点。
- `scene.json` 记录各层摘要、原文件、指令、固定注册和预留站位；单层开关保留真实透明区域。

## 重组与可编辑原稿

`preview.html` 按上表顺序直接显示四张 PNG，可独立开关与显示站位导线。`review.png` 是该页面仅场景区域在 Chromium 中的原尺寸截图，不含人物或站位导线，不是重新生成的一张扁平示意图。用户审核以此原图为准；HTML 仅作为资源交接时的辅助，不要求用户在 iPad 下载打开 HTML。

`camp-clearing-layers.ora` 含四张未改字节的原图层、固定坐标、图层顺序和实际重组预览，可在支持 OpenRaster 的绘图软件中打开。不是对已认可单张原图做无损语义分离：这些环境层按原样板分别重绘并补全隐藏内容，纹理和个别轮廓会有差异，需审核当前重组图。

交接复现：已安装 Node.js、Playwright 与 Chromium 的环境中运行 `node source/render-preview.cjs`，会从四张图层重新导出 `review.png` 并检查逐层开关及统一缩放；浏览器路径可由 `CHROMIUM_PATH` 指定。该工具只渲染 PNG 图层，不重画或修改图层像素。
