# M1/M2 实施记录 · Build73

2026-11-04。M1纯生成器与M2原生设置/林地预览已实现，源提交 `7c558bed56b8057300433d1222e9aeaaca04fa9f`。设备构建与交付状态以 `Media/Build73` 回执为准，不把源码完成当作已安装测试。

- 新目标 `MeadowWorldSupport`：配置校验、固定SplitMix64子流、网格邻接候选边上的随机连通树/精确环路、按远近挑Boss、精确节点类型配额、带弧度道路、营地/树石/花草避让。0 Boss/0战斗合法；不满足数量/环路/Boss距离条件时明确失败，最多64次构造尝试。生成快照包含版本、配置、GameMap、道路与props。
- 新界面 `MeadowMapSettingsViewController`：总数4—30，起点1；战斗/Boss/奖励/空地/额外道路/种子分别输入。改总数不自动覆盖手动数量；采用建议才重新分配。无效总和显示差额且不能生成。结果过期立即禁用进入；后台生成有revision防止迟到结果覆盖新输入。两列可分别滚动，窄屏仍能访问所有输入和操作。
- 原地图左下“随机地图”进入。生成缩略道路后“进入林地预览”复用原GameViewController/MeadowLoader/SpriteKit/Metal素材和投影加载，返回仍保留设置结果。预览禁用营地换装/战斗演练入口，明确写出战斗和奖励暂不结算。
- `SceneDefinition.generated`把同一GameMap的实际节点/道路转换成画面坐标，原静态地图的可选字段缺省与原巡逻路线保持。生成图的巡逻沿所有真实分叉往返，出生来自实际起点；三人初始位置沿道路间隔30，未换人体/步态。生成地图不读取固定营地避让矩形，也不访问discoveries[1]。

实际配置格式见 [actual-configuration-example.json](actual-configuration-example.json)，与最初研究里的提案结构区分；这是Swift生成器配置，不是已开放的App配置文件导入功能。

验证和完整离线素材见 [审核目录](../../../Art/Review/Map/random-map-v1/README.md)：179项包测试（含5项新地图测试）、648组精确配额与图校验、78组实际适配/曲线/巡逻/交叉/占地检查；独立临时构建重新导出的9组地图与400动作采样逐字节一致。13个上游规则/目录文件摘要未变。动态图来自正式Swift路径/动作采样和现有PNG，阴影/道路着色/环境光是离线近似，不是设备或Metal截图。

首版布局仍基于网格邻接走廊，随机位置与弧线让道路产生变化，尚非任意地形/自由道路编辑器。当前没有战役存档、实际怪物单位投放、奖励领取、正式节点探索战斗或单节点编辑命令；不把它们说成已接入。下两项为M3共享正式探索引擎+实际地图存档，再M4节点内容编辑。原营地档案由原流程维护，随机预览不修改营地存档。
