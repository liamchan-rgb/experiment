# Build78 · 随机地图地点内容编辑

Build78（1.6.51/78）为随机地图增加暂停状态下的地点内容编辑，地图节点数量、坐标、建筑和道路保持原样。

## 已实现

- 普通战斗地点可配置 1–3 只怪物；首领地点固定 1 只。怪物模板先由游戏目录校验，再以稳定的节点单位 ID 写入当前地图。
- 补给地点可编辑金币、积分和药水数量。编辑已领取的补给只更新未来配置，不会自动清除领取标记或再次发奖。
- 已领取补给只有通过单独的“重置已领取状态”并再次确认后才重开；重开后在真正抵达该节点时结算一次。
- 移动中、战斗中不可编辑。每次变更通过游戏命令写入操作历史和存档，存档版本维持 1。
- UI 只列可编辑的战斗、首领和补给地点；四个底部按钮按屏幕宽度自适应排布。

## 验收

两个新增的纯 Swift 回归分别覆盖怪物模板校验/替换/历史/续档，以及已领取奖励的修改、显式重置、再抵达只发一次。现有随机地图和战斗回归继续执行。iOS 设备 Release 只归档，不在 CI 里启动模拟器或 App；安装和实机表现由用户侧验证。
