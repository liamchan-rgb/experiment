# M3首版 · Build76 · 正式行程与三倍速度

沿用已认可的生成器v3/建筑资源，新增独立MeadowCampaignSession与campaign-v1.json，营地camp-v1.json保持。设置可先预览、开始新行程或继续存档；已有行程会在替换前由界面明确确认，读取失败不会覆盖旧档。首版沿用已验证双人战斗布局：P1魔剑士、P2游侠，装备/衣装从营地复制，起始补给单独初始化；跨遭遇和继续存档不重置生命、药水、装备、金币、积分或RNG。原地图演示仍三名旅人。

规则GameMap先按道路数选路径并由GameEngine.preview验证；保存同一条节点路径，遇首个未激活敌人停步。画面逐边使用原生成道路采样，沿途到站时每边一次GameEngine.move，故不在出发时揭示/领终点奖励。每人每边1AP，同到奖励均按原规则领取，重访不发第二次。探索规则本来没有自动回合，界面“补足行动”明确调用原refillExploration，仅在不移动且无战斗时可用。地图生命用血条，行动点用原黄色菱形，道具/救援依原目标及AP校验。

移动游标保存操作ID、同行者、实际路径、当前边、距离、暂停及镜头；读档先暂停，真实布局/节点状态/完整GameArchive直接恢复，不按seed重新生成。到达持久化失败则不扣AP/不发奖励/不揭示，内存暂停供重试。原子写成功后引擎才提交；命令ID重试不重复奖励。

PartyEncounter新增同一GameEngine注入，确认时仍在隔离引擎固定一次骰值，真实命中才在原引擎apply并保存，不再替换为无持久化的演练引擎。正式怪物行动使用原monsterStep策略/目标/RNG；遇敌与结束战斗沿原规则。每个节点怪物ID独立，映射到已验证的两个战斗站位；恢复时已死怪物不重新站起。关闭/切后台取消尚未命中的演出并保存当前真实状态，不返还已结算伤害或再次结算。支持未结束战斗续接、胜利返回与倒地状态保存，无重置演练按钮。

现有鹿灵美术承载两个明确的本地模板：普通鹿灵复制原wolf的全部数值/AI/掉落，鹿王复制原caveTroll（包括再生与横扫）；仅ID/名称变化，原六怪物条目及19技能/18物品不改。普通节点1或2只、首领1只，不把节点数量当怪物数量。再生复用已有治疗精灵/混帧与绿光，不新增人物动作。尚未制作六种原怪物的独立外观，不冒称已齐全。

地图移动统一倍率3：原演示P1 25→75、P2 38→114、P3 45→135，实际屏幕距离仍用原投影度量；正式同行队伍按队伍最低速度前进。现有距离驱动步相自然随实际距离推进，起停原画/挂点与战斗出招时序保持。该倍率是用户本轮明确要求，优先于历史速度25约束。
