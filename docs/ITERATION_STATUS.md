## 2026-10-15 视觉反馈回合

用户新增验收问题：旗帜与建筑错位、阴影整体漂移、斜向行走显得蹩脚、花簇／小植被像贴图覆盖草地。

源码检查确认：帐篷素材已经带有旗面，运行时又叠加通用旗帜；瞭望塔旗帜锚在整张素材的上沿，没有落到屋脊。两处已调整为仅给瞭望塔添加旗帜，并按塔顶和旗杆锚点定位。花簇素材底部有自带草垫，现为其底缘添加世界坐标噪声过渡。

当前轮还将太阳方向设为缓慢变化的单一方向光，地面光束、人物投影和物件投影共用该方向；人物投影跟随步态抬步。阴影仍是实时更新的 2.5D 透明轮廓投影，不是 SpriteKit/Metal 的三维 shadow map。本轮 CI 和画面复核完成后再判断是否需要替换渲染路径。

步态方向切换的迟滞区缩小，并在交替接触姿态之间加入轻微抬步。现有角色素材只有正面、背面和左右侧面四个朝向，没有四种斜向的独立姿势；代码可减少斜线路径上的朝向滞后，但要彻底消除斜向“蹩脚感”，还需要生成并验收斜向动作素材。

本轮源码对应 1.2.0 build 6，等待 GitHub Actions 原生编译、渲染像素检查、iPhone/iPad UI 测试和录像复核；尚未作为真机安装包交付。
