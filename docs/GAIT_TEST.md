# iPad 八方向步态测试

进入地图后，点击顶部“步态测试”。默认观察左上 ↖；P1、P2、P3 同时沿选定方向走直线，走完一段后回到起点继续同方向。

- 八个方向可以直接选择，不需要地图上存在相应道路。
- “切换慢速”使用四分之一速度，动作仍按实际行走距离推进。
- “暂停”保留当前姿势，“单步”推进二十四分之一个步态周期（下一张完整姿势帧）；单步也会自动暂停。
- “重新走”回到该方向起点；顶部“返回地图”恢复进入测试前的相机、人物位置和播放状态。

## build 27：检查鞋子朝向

安装 1.6.2 build 27 后，点击主地图顶部“步态测试”。P1、P2、P3 会一起沿选定方向走直线；鞋部保留各方向原图角度并随脚踝移动。本轮要检查三位人物在八个行走方向的鞋尖朝向和落脚状态。

1. 依次选择上、左上、左、左下、下、右下、右、右上，观察鞋尖方向与人物前进方向是否协调。
2. 先看正常速度，再点“切换慢速”。留意左右脚交替时鞋子是否突然反转、歪斜或偏离脚踝，以及鞋腿交界是否断开。
3. 遇到可疑动作时点“暂停”，再用“单步”查看相邻姿势；用“重新走”重播当前方向。
4. 检查 P1、P2、P3 后点“返回地图”，确认返回后可正常缩放、拖动和行走。

“原图 / 分层蓝靴对照”是附带的换色小样，只覆盖 P1 向下；它不用于检查其余七个方向的鞋向。

反馈时注明 build 27、人物、行走方向、正常／慢速、iPad 型号和系统版本，以及问题表现或暂停单步时的姿势。安装与下载见 [Downloads/README.md](../Downloads/README.md)。

反馈时注明人物、方向、正常／慢速，以及问题表现，例如“P1 左上，慢速时右腿一直拖地”或“P3 右下，换腿时靴子突然跳动”。可以暂停、单步定位具体姿势。

build 25 重做三位人物的八方向行走，每方向 24 张完整姿势；旧 build 24 仅调整左上腿区的方式已经弃用。本轮恢复云端运行与录像检查。测试复用游戏的显示与实时阴影流程；不将源图对照、数学检查或成功归档当作动作自然度通过。
