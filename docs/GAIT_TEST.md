# iPad 八方向步态测试

进入地图后，点击顶部“步态测试”。默认观察左上 ↖；P1、P2、P3 同时沿选定方向走直线，走完一段后回到起点继续同方向。

- 八个方向可以直接选择，不需要地图上存在相应道路。
- “切换慢速”使用四分之一速度，动作仍按实际行走距离推进。
- “暂停”保留当前姿势，“单步”推进八分之一个步态周期；单步也会自动暂停。
- “重新走”回到该方向起点；顶部“返回地图”恢复进入测试前的相机、人物位置和播放状态。

反馈时注明人物、方向、正常／慢速，以及问题表现，例如“P1 左上，慢速时右腿一直拖地”或“P3 右下，换腿时靴子突然跳动”。可以暂停、单步定位具体姿势。

build 24 只调整左上朝向的腿区对齐，其他方向保留原效果以便逐项比较。测试复用游戏的显示与实时阴影流程；不将源图对照、数学检查或成功归档当作动作自然度通过。
