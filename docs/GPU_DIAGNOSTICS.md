# iPad GPU 取证包使用方法

build 24（1.5.11）沿用单 MTKView 合成与诊断，校准左上行走的腿区并加入[八方向步态测试](GAIT_TEST.md)。此前的栅栏、光束修改保留。用户已确认 build 21 能在此前报错的 M1 iPad Pro 打开地图；这不等于长时间运行和新版本视觉效果都已通过。

1. 用 SideStore 安装 build 24。测试前从后台完全关闭 MeadowJourney，再打开应用。
2. 应用自动运行 A、B 分通道检查、C00 连续 60 帧组合检查，再进入 C02 实际地图。加载页始终提供“复制诊断”。
3. 若显示失败，点击“复制诊断”，将文字粘贴到对话中。若应用被系统关闭或完全卡住，退出后台再打开；此时会保留上次记录，先复制，再决定是否点“重新诊断”。

报告包含包版本、硬件标识、系统版本、GPU 名称、目标像素尺寸、阶段提交／完成情况、GPU 时间（驱动提供时）、首次错误的域和代码，以及编码器错误信息（系统提供时）。同一次诊断的后续错误不会覆盖首次错误。每次提交前将小型 JSON 原子写入 Documents/MeadowGPUDiagnostic.json，复制按钮直接读取当前记录，不需要连接 Xcode。

新版本不会把旧版本失败当作本次失败；开始新一轮时，将此前记录另存为 Documents/MeadowGPUDiagnostic.previous.json。编码器状态同时记录名称：rawValue 2 为 completed，4 为 faulted；故障编码器仍不等于已定位到某条 shader 指令。GPU 命令失败后需完全结束进程，避免继续收集被忽略的提交。

| 阶段 | 执行内容 | 能说明什么 |
| --- | --- | --- |
| A01 | 原生 Metal 清屏 | 基础命令能否完成 |
| A02 | 正式地表材质，关闭阴影采样 | 地表片元管线单独执行的情况 |
| A03 | 全场景物件与待机人物的阴影深度 | 深度投影管线单独执行的情况 |
| A04 | 地表接收前一步深度图，执行 PCF | 阴影采样管线单独执行的情况 |
| B01 | 普通贴图前景 | SpriteKit 基础素材与离屏渲染 |
| B02 | 全物件植被着色器 | 植被着色器及物件规模 |
| B03 / B04 / B05 | 后雾／光束／前雾分别执行 | 各全屏效果的执行情况 |
| B06 | 完整前景组合 | 前景效果组合后的执行情况 |
| C00 | 60 帧完整组合：深度、地表、背景呈现、SpriteKit 前景 | 重用生产资源和组合代码时，连续提交能否完成 |
| C02 | 实际单 MTKView 地图 | 完整地图命令缓冲区的 GPU 完成与真实 drawable 呈现路径 |

A 组在 SpriteKit 纹理创建、预加载和渲染之前串行执行，每个通道使用独立命令缓冲区。B 组通过 SKRenderer 在前景实际像素尺寸离屏运行，每项在两个时间点各提交一帧；收到 GPU 完成回调后才进入下一项。A／B 检查不读取或分析图像像素。

C00 每帧强制更新阴影与地表，重用同一深度图、背景纹理和前景目标；只保留前两帧、末帧的详细事件，并累计全部 60 帧的 GPU 时间统计，不读取图像像素。

C02 不再将原生地面提交嵌入 SKScene 更新回调，也不再使用独立 SKView 呈现前景。一个 MTKView 的显示回调先更新场景，再将原生背景、Retina 呈现和 SKRenderer 前景编码到同一个命令缓冲区，最后呈现一次 drawable；最多一帧在 GPU 执行。地表保持每 UIKit point 一个像素、上限 30Hz，前景保持 Retina 尺寸、目标 60Hz；2048² 轮廓实时阴影不降级。相机和触摸都通过同一场景节点变换取样。

首个完整组合命令完成后才解除加载页。报告累计实际地图完成帧数、平均／最低／最高 GPU 耗时；失败时另记帧号与环境时间，编码器标签可以区分深度、地表和背景呈现。实际运行汇总记录每 60 帧持久化，避免每帧磁盘写入。

证据边界：C00 离屏通过不能保证真实 drawable、长时间运行、缩放或移动通过；C02 首帧成功也不能保证后续帧。应用退出时最后一项只有 submitted、没有完成记录，说明检查中断，不能单独证明该项导致 GPU 错误。如果首次看到的已经是 SubmissionsIgnored，也不能从该错误反推出更早的根因；需要完全退出进程后重试。build 20 的 C01 双视图记录保留为历史证据，不能与 build 21 的 C02 混同。

按用户要求，本包云端只编译并归档，不运行模拟器或云端 GPU 验收。物理 iPad 上生成的报告才是本轮需要收集的证据。
