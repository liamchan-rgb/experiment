# 贴图轮廓实时阴影

## 1.5.2 build 15

build 12 的小场景轮廓效果已由用户确认。本轮将同一图像 alpha 裁切、少量纵深分层和实时 shadow map 扩展到主地图，删除简模网格与模式切换。

覆盖 OakA、OakB、Pines、WatchTower、CampTent、Fence、RockLow、RockHigh、RockSmall、Shrub、Flowers、Banner，以及三位旅人的八方向当前帧。每类资源配置接地点和纵深规则；实例的坐标、尺寸、镜像及风参数驱动贴图与投影，不为地图预烘焙阴影。旗杆下段仍由塔楼屋顶遮挡。

主地图由原生 Metal 不透明地面通道绘制草地和合并道路；各类轮廓分组写入 2048² depth32Float shadow map，再以 PCF 接收到同一地面颜色输出。删除 build 14 依赖独立 SKRenderer 地形通道的路径，修复用户反馈的整层黑底；前景透明属性在首次呈现场景前设置。透明 SpriteKit 前景保留原交互、人物及氛围；相机位置、缩放和太阳参数共享。显示路径不读回 GPU 图像，不以 CPU 图像复制传递阴影；仅原生回归测试读取最终颜色验证地面。试验场继续使用用户确认的 1024² 通道，仅保留轮廓投影。

## 同轮修正

角色 Directions／Diagonals 已包含完整的左右脚交替帧；旧着色器又按膝下区域反射／平移另一条腿，使帧 3 出现接缝。删除这层二次交换，完整人物帧负责姿态，环境着色器只处理环境光。人物深度投影读取同一朝向和帧。build 15 进一步移除额外全身抬升；向右整体镜像用户认可的向左帧，其他朝向以 8×8 连续下肢网格补充承重脚后扫。该网格与相位同时用于可见人物和深度 caster，脚部位移沿地面处理，不引入膝下切片。左右 profile 保持源动画；正背向缺少分离脚底的素材仍限制完全锁脚。

道路从逐段不透明多边形改为全图距离并集遮罩。交叉口共用一次材质合成，边缘加入多尺度扰动、透明衰减和稀草保留；降低黄砂色的亮度与饱和度，增加细微车辙、斑驳裸土和少量碎石。草地在过渡带自然透出，避免多段叠色与硬边。减少路边密集花点。

## 检查与反馈

build 14 的检查仅验证了 GPU 提交与交互，未覆盖最终地面像素；用户实机截图证明此范围不足。本轮新增不透明纹理地面、道路／阴影颜色差分，以及 iPhone／iPad 实际合成屏幕在初始、缩放和试验场返回后的非黑覆盖率检查。阴影及道路的美术效果仍由用户安装反馈。

历史 build 14 源码 `cc3b7b9` 的构建 `38775110277` 通过编译、设备归档、8 项原生检查及 1 项 UI 交互检查（0 失败）。安装包为 [MeadowJourney-b14.ipa](../Downloads/MeadowJourney-b14.ipa)，来源与 SHA 见 [MeadowJourney-build14.json](../Downloads/MeadowJourney-build14.json)。

build 13 曾在 SpriteKit 更新回调内同步触发 `MTKView.draw()`，最终 UI 缩放查询超时。build 14 的首个独立显示时钟候选仍出现交互超时，未发布。最终版恢复单一场景驱动，背景上限 30fps，镜头、视口或人物动作帧变化时立即更新；背景视图保持暂停其自身时钟。每帧呈现／提交后显式释放 MTKView 的 drawable 缓存引用，由 command buffer 持有已提交资源直至完成。build 13 已由此替换。

当前为图像驱动的 2.5D 近似；物件表面接收其他物件投影、不可见背面体积，以及物理设备帧率／发热仍需后续验证。

## 1.5.3 build 16：共享实际视口与分阶段加载

主地图每帧采样 SpriteKit 的 world→scene→view 变换，原生 Metal 接收通道直接使用该快照。旧理想公式在统一缩放与平移条件下代数等价，因此本轮不把单个漏乘的缩放系数当作已证明根因。实际前景红点与地面青环在 100%、125%、150%、175%、双指缩放上限和复位后比较中心；原生检查另覆盖平移及不同视口。

启动道路遮罩、资源准备、原地分组网格、Metal 纹理上传和光效准备移至后台。加载条会分别显示投影队列、阴影深度贴图、两个 Metal 着色器、物件网格、环境贴图、人物图集与地表遮罩的实际阶段；失败诊断保留当前阶段和错误。前景实际 SKView 再分阶段预热贴图、无纹理／加色管线、字形、形状和粒子；不使用会阻塞的后台 SKRenderer。主线程每批布置 8 个物件，并让出事件循环；删除主地图中已被原生地面通道取代的多余 SpriteKit 地形构建。人物投影使用预先上传的完整图集，切帧只改 UV 范围。

加载页显示实际阶段进度，以前景首个更新及地面 GPU 完成为操作放行条件；GPU 失败或首帧等待超时显示重试，迟到回调不会覆盖失败状态。应用挂起不消耗首帧等待的活跃心跳限额。记录加载耗时、心跳次数和主线程最长间隔；它们是模拟器观测，不代替物理设备性能结果。行走动画按用户要求推迟。
