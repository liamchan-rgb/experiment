# 贴图轮廓实时阴影

## 1.5.0 build 13

build 12 的小场景轮廓效果已由用户确认。本轮将同一图像 alpha 裁切、少量纵深分层和实时 shadow map 扩展到主地图，删除简模网格与模式切换。

覆盖 OakA、OakB、Pines、WatchTower、CampTent、Fence、RockLow、RockHigh、RockSmall、Shrub、Flowers、Banner，以及三位旅人的八方向当前帧。每类资源配置接地点和纵深规则；实例的坐标、尺寸、镜像及风参数驱动贴图与投影，不为地图预烘焙阴影。旗杆下段仍由塔楼屋顶遮挡。

主地图以 SKRenderer 绘制地形和合并道路，Metal 将各类轮廓分组写入 2048² depth32Float shadow map，再以 PCF 将投影合成到草地和路面。透明 SpriteKit 前景保留原交互、人物及氛围；相机位置、缩放和太阳参数共享。不读回 GPU 图像，不以 CPU 图像复制传递阴影。试验场继续使用用户确认的 1024² 通道，仅保留轮廓投影。

## 同轮修正

角色 Directions／Diagonals 已包含完整的左右脚交替帧；旧着色器又按膝下区域反射／平移另一条腿，使帧 3 出现接缝。删除这层二次交换，完整人物帧负责姿态，环境着色器只处理环境光。人物深度投影读取同一朝向和帧。

道路从逐段不透明多边形改为全图距离并集遮罩。交叉口共用一次材质合成，边缘加入多尺度扰动、透明衰减和稀草保留；降低黄砂色的亮度与饱和度，增加细微车辙、斑驳裸土和少量碎石。草地在过渡带自然透出，避免多段叠色与硬边。减少路边密集花点。

## 检查与反馈

本轮对照三位人物八方向的完整接触帧，执行原生步态、主地图全资源深度提交、资源坐标对齐、道路交叉口顺序无关性和 UI 交互检查。阴影及道路的最终画面由用户安装反馈；不再以测试通过替代美术验收。

最终源码 `42f0d68` 已完成设备归档，安装包为 [MeadowJourney-b13.ipa](../Downloads/MeadowJourney-b13.ipa)。最后一轮针对性检查进行中；来源与校验值见 [MeadowJourney-build13.json](../Downloads/MeadowJourney-build13.json)。

当前为图像驱动的 2.5D 近似；物件表面接收其他物件投影、不可见背面体积，以及物理设备帧率／发热仍需后续验证。
