# 三维实时阴影小场景

## 1.4.1 build 12：贴图轮廓试验

按用户要求，画面效果由用户自行检查反馈；本轮只做编译、基础 Metal 命令执行和 IPA 完整性检查，不进行图片复核、录像验收或像素效果对比。

默认「轮廓投影」使用贴图坐标生成 2.5D 深度网格：树冠以平滑过渡的三层纵深代替圆体，塔楼沿支柱／屋顶分配纵深，人物使用当前动画帧。顶点高度补偿纵深位移，让固定相机中的投影保持贴图位置；深度通道以 PNG alpha 裁掉透明处。底部地面草垫不作为直立体积投影。

「轮廓投影／简模投影」切换新旧方案；「模型显示」在轮廓模式中显示按 alpha 裁切的网格参照，旧简模模式仍显示线框。两种模式继续使用同一 1024 深度贴图、太阳和地面接收流程。此方案是图像驱动的 2.5D 近似，未恢复贴图背面或隐藏体积。

快速打包入口：手动运行 iOS Build and Visual Demo 并设置 `quick_lab=true`，仅归档 IPA 和执行 `testShadowLabCutoutPipelineSubmitsBothCasterModes`；没有图像读取／对比断言。

状态：1.4.0 原型开发中，待原生构建及画面验收。

从地图左上方的「光影试验」进入，或用启动参数 `-shadowReview` 直接启动。原地图保持现有 SpriteKit 实现，便于对照；本轮先验证树、瞭望塔和左行人物，没有把全地图切换到新渲染器。

## 实现

- 独立 `MTKView`，所有 pass 使用同一个 Metal device 和 command buffer。正常显示没有 CPU 图像回读。
- 统一右手世界坐标：XY 为地面、Z 为高度；同一个实例记录驱动美术和三维代理的位置、比例及接地点。
- 塔楼四根柱脚以图片归一化地标记录，按相机投影反算地面位置；代理高度补偿底座中心的纵深，让柱脚与屋顶同时对应素材。
- 三维网格先绘入 1024 × 1024、depth32Float 的真实深度阴影贴图。地面使用同一太阳矩阵进行深度比较和 3 × 3 PCF；二维人物轮廓不参与此深度 pass。
- 地面绘制后透明合成现有 RGBA 素材；旗帜先绘制，塔楼后绘制，让屋顶遮住旗杆下段。
- 树卡片与三维树冠共享风动函数；人物素材帧与三维腿部代理共享接触帧编号，代理根点固定在地面。人物先校准左行素材，返程同步镜像图片和代理，八方向完整动作仍在待修清单中。
- 「换一组布局」复用每类素材的代理配置，同步更新可见物件和投影实例；这是随机地图接入的最小验证。

## 操作与验收

- 「阳光自动／固定」与滑杆调整光向；「投影开启／关闭」用于同画面对照。
- 「模型显示／隐藏」叠加三维代理线框，检查图像接地点、支柱、树冠与人体的对应关系。
- 「暂停动态」冻结运动，双指缩放检查放大和缩小时的对应关系；「返回地图」回到原场景。
- GPU 回读测试分别检查深度贴图包含网格、树根／塔柱／落地脚附近的实际投影，以及太阳、树风和腿部姿态对投影的影响。截图和连续录像仍需人工复核，测试通过不代表美术验收通过。
- `-shadowReviewDemo` 自动展示线框、光向切换、阴影开关及重新布局，供 CI 录屏。运行采样写入 `Documents/ShadowLabMetrics.json`。

## 当前边界

只有单一方向光和地面接收阴影。代理是手工简模，其细节和姿态对应仍需按实际画面校准；二维物件表面相互接收阴影尚未实现。没有替换现有角色八方向动作或道路材质。模拟器编译、GPU 渲染和录屏用于原型验证；设备帧率、耗电和发热需用 IPA 在物理 iPhone／iPad 上测量。
