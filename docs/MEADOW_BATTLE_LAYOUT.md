## 当前实现

- 共用顶部：当前行动者、示例轮次、布局演示标识和三态切换。
- 中部：地图与战场等高；16:9 左右宽度参考 760:944，4:3 参考 596:676，适配实际窗口及安全区。战场使用整个右区。
- 底部：完整连续轨道跨越整屏，示例为7玩家与3敌方，保留稳定ID、已行动段、当前指针、倒地标记和下轮标记。
- 玩家回合：轨道下展开紧凑技能／物品／资源；怪物回合收起详情并释放高度；探索时战场、战斗轨道和详情一起收起，地图扩展。
- 地图仍是实时 MTKView，透明外层把地图区域的点击／缩放／拖动传给原视图；退出恢复原相机与缩放。
- 战场图像采用获认可的四层原始 1309×1201 画布，全层共用等比 contain 和居中变换，不裁切、不拉伸。顺序为远景树林、地面、中景营地／岩石、角色接地影、人物、敌人、前景遮挡。
- 人物从 `Hero1Directions` 右向 idle 格切出，沿用已认可场景中的脚底 `(0.30,0.69)`，可见高度为画布的12%。敌人采用独立左向鹿灵精灵，不从桌游仓库复制；暖棕／苔绿／琥珀配色与 Meadow Journey 林地相连，固定脚底 `(0.70,0.685)`，可见高度为画布的38%，形成参考中的小人物／大型敌方比例。scene.json 的24%人物／8.5%敌方只是原环境样板预留值；运行时按实际运行图 alpha 外接框注册。环境层统一等比居中，人物与敌方使用最近邻像素缩放；各自接地影独立绘制，敌方阴影铺在躯干下方并降低不透明度。

## 演示数据与边界

顶部始终写明“布局演示”。切换探索／玩家／怪物仅查看排版，不触发桌游回合、技能、伤害、背包或地图移动。Meadow 地图仍显示原来的3位旅人；下方7玩家是布局密度样例，复用地图头像并用P1—P7区分，敌方队列头像仍是系统爪印。右侧目前是静态的一人一怪美术样例，不代表完整队伍阵位或角色动画。

技能样例按桌游 `native/Packages/GameCore/Sources/ClassroomGameCore/Resources/initial-content.json` 冒险者定义抄录：`heavyStrike` 强击1AP、射程0、1D6+2、2次；`breather` 喘息1AP、恢复4生命、2次；`simpleGuard` 简易防护1AP、4护盾、2次。样例用初始生命12/12、盾0、金币0、积分0和空背包，不读取真实桌游存档。来源文件SHA-256：`aaab980fd5f3154ac813a02dc907a835ee0e0181c4149f2b7803d9594795f34a`。

真实当前行动者、混合队列、节点遇敌、背包与合法性、技能结算、角色动画仍须与桌游数据和规则正式连接。桌游仓库、本局规则和存档格式未改。环境四层曾获固定镜头美术认可；本次的人物／敌方接入是新构图，鹿灵也只是未获用户审美认可的静态资源样例，构建和模拟器截图不代表美术通过。
